# Step 2. Specify Organization Name and Description


At the Info step of the wizard, enter a name for the new AWS Organization and provide a description for future reference. The name must be unique in the backup appliance; the maximum length of the name is 127 characters; the maximum length of the description is 255 characters.

|  |
| --- |
| Important |
| The names of organizations and IAM roles that you add to the backup appliance must not match. |
