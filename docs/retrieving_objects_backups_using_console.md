# Retrieving Objects Backups using Console


To start the retrieval of archived backup files, use the Retrieve Backup wizard.

1. [Launch Retrieve Backup wizard](os_data_recovery_retrieve_launch.md).
2. [Select Retrieval Mode](os_data_recovery_retrieve_mode.md).
3. [Select Availability Period](os_data_recovery_retrieve_period.md).
4. [Finish Working with the wizard](os_data_recovery_retrieve_summary.md).
