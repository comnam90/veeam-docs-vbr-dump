# Creating File Backup Jobs Using Web UI


Before you create a file backup job, check [prerequisites](file_share_backup_job_before_you_begin_web.md),

To create a file backup job, use the New Backup Job wizard:

1. [Launch the New File Share Backup wizard](file_share_backup_job_launch_wizard_web.md).
2. [Specify the job name and description](file_share_backup_job_name_web.md).
3. [Select files and folders to back up](file_share_backup_job_files_and_folders_web.md).
4. [Specify backup repository settings](file_share_backup_job_storage_web.md).
5. [Specify advanced backup settings](file_share_backup_job_advanced_settings_web.md).
6. [Specify archive repository settings](file_share_backup_job_archive_repo_web.md).
7. [Define the job schedule](file_share_backup_job_schedule_web.md).
8. [Finish working with the wizard](file_share_backup_job_summary_web.md).
