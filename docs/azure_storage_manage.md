# Managing Storage Templates


A storage template is a collection of settings that allows you to define target locations (that is, repositories where backup appliances keep restore points produced by SLA-based backup policies) for backups and archived backups. One storage template can be assigned to one or more SLA-based backup policies. For more information, see [Storage Templates](azure_storage_template_hiw.md).
