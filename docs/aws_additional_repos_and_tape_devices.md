# Additional Repositories and Tape Devices


Additional repositories and tape devices are any repositories where Veeam Backup & Replication keeps and stores copies of VM instance backups. For more information, see sections [Backup Repository](https://helpcenter.veeam.com/docs/backup/vsphere/backup_repository.html?ver=120) and [Machines Backup to Tape](https://helpcenter.veeam.com/docs/backup/vsphere/backup_to_tape_jobs.html?ver=120).
