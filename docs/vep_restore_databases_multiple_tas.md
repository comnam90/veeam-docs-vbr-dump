# Restoring to Another Server


You can restore multiple PostgreSQL databases to another server or to the same server but with different settings.

To restore multiple PostgreSQL databases, use the Restore wizard.

1. [Launch the Restore wizard](vep_restore_databases_multiple_tas_wizard.md).
2. [Specify a restore point](vep_restore_databases_multiple_tas_specify_restore_point.md).
3. [Specify a target server](vep_restore_databases_multiple_tas_specify_target_server.md).
4. [Specify PostgreSQL settings](vep_restore_databases_multiple_tas_specify_postgresql_settings.md).
5. [Specify the database account](vep_restore_databases_multiple_tas_specify_db_account.md).
6. [Specify database names](vep_restore_databases_multiple_tas_specify_db_name.md).
