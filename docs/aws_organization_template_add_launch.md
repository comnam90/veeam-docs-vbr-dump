# Step 1. Launch Create IAM Role Template Wizard


To launch the
Create IAM Roles Template
wizard, do the following:

1. Switch to the
   Configuration
    page.

1. Navigate to
   Infrastructure
    >
    Organizations
   .

1. Click
   Create Template
   .
