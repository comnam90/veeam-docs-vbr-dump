# Managing AWS Organizations


To be able to perform data protection and disaster recovery operations with AWS resources that belong to AWS accounts within an AWS Organization, you can add the AWS Organization to the backup appliance and specify IAM roles whose permissions will be used to perform these operations. To help you configure the necessary IAM roles in AWS and grant all the required permissions, the backup appliance allows you to [create IAM roles templates](aws_organization_template_add.md).
