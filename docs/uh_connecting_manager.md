# Connecting Universal Hypervisor Manager


A Universal Hypervisor Manager is a server that allows the backup server to access universal hypervisor resources such as VMs, datastores and networks. After you add a Universal Hypervisor Manager to the backup infrastructure, you will be able to deploy workers and to manage data protection tasks for VMs running on a universal hypervisor.
