# Step 6. Configure Backup Target Settings


By default, backup policies create only backups of processed EFS file systems. At the Targets step of the wizard, you can specify the following backup target settings:

* [Specify backup vaults where the backup appliance will store EFS file system backups](aws_add_policy_target_settings_backups_efs.md).
* [Instruct the backup appliance to copy EFS file system backups to other AWS Regions](aws_add_policy_target_settings_backup_copy_efs.md).
