# Adding Citrix XenServer Pool to Backup Infrastructure


To add a Citrix XenServer pool to the backup infrastructure, do the following:

1. [Launch the New Citrix XenServer pool wizard](xen_server_add_launch.md).
2. [Specify the Citrix XenServer pool coordinator domain name or IP address](xen_server_add_name.md).
3. [Enter credentials to access the Citrix XenServer pool](xen_server_add_credentials.md).
4. [Apply Citrix XenServer pool settings](xen_server_add_apply.md).
5. [Finish working with the wizard](xen_server_add_summary.md).
