# Creating Replication Jobs


To create a replication job, do the following:

1. [Check prerequisites and limitations](pve_replication_job_create_prerequisites.md).
2. [Launch the New Replication Job wizard](pve_replication_job_create_launch.md).
3. [Specify a job name and description](pve_replication_job_create_info.md).
4. [Select VMs to replicate](pve_replication_job_create_vms.md).
5. [Specify a destination for replicas](pve_replication_job_create_destination.md).
6. [Configure network mapping](pve_replication_job_create_network.md).
7. [Configure replication settings](pve_replication_job_create_settings.md).
8. [Create a schedule for the replication job](pve_replication_job_create_schedule.md).
9. [Finish working with the wizard](pve_replication_job_create_summary.md).
