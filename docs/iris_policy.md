# Working with Application Backup Policy for InterSystems IRIS Instances


To back up InterSystems IRIS instances with Veeam Backup & Replication, you must create an application backup policy. A backup policy defines which instances to protect, where to store the backup data, and on what schedule backups run. For details, see [Creating Application Backup Policy](iris_policy_create.md).

After you create a policy, Veeam Backup & Replication backs up InterSystems IRIS instance data according to the policy settings and schedule. You can also can perform a set of other operations with an application backup policy manually. For details, see [Managing Application Backup Policy](iris_policy_manage.md).
