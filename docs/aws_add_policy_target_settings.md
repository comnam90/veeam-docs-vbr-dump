# Step 6. Configure Backup Target Settings


By default, backup policies create only cloud-native snapshots of processed instances. At the Targets step of the wizard, you can enable the following additional data protection scenarios:

* [Instruct the backup appliance to replicate cloud-native snapshots to other AWS accounts or AWS Regions](aws_add_policy_target_settings_replica.md).
* [Instruct](aws_add_policy_target_settings_backups.md) [the backup appliance](aws_add_policy_target_settings_replica.md) [to create image-level backups](aws_add_policy_target_settings_backups.md).
