# Launching Veeam Explorer Using Console


To restore application items from image-level backups, you can use the item restore wizard in the Veeam Backup & Replication console.

1. [Launch the wizard](restoring_veeam_explorers_launch.md).
2. [Select a machine or site](restoring_veeam_explorers_vm.md).
3. [Select a restore point or content database](restoring_veeam_explorers_point.md).
4. [[For restore from storage snapshots] Select an ESXi host for snapshot mounting](restoring_veeam_explorers_host.md).
5. [Specify a restore reason](restoring_veeam_explorers_reason.md).
6. [Open Veeam Explorer](restoring_veeam_explorers_open.md).
