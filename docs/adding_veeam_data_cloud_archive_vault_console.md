# Adding Veeam Data Cloud Vault Archive Using Console


To add Veeam Data Cloud Vault Archive using console, use the New Object Storage Repository wizard.

1. [Launch the New Object Storage Repository wizard](new_object_repository_veeam_data_cloud_console.md).
2. [Specify an object storage name](veeam_data_cloud_archive_name_console.md).
3. [Specify object storage account](veeam_data_cloud_archive_account_console.md).
4. [Specify object storage settings](veeam_data_cloud_vault_details_console.md).
5. [Finish working with the wizard](veeam_data_cloud_archive_finishing_wizard_console.md).
