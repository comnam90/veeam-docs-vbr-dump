# Rolling Back to a Point in Time Using Web UI


Before you roll back the file share to a point in time, [check prerequisites](roll_back_to_point_in_time_before_you_begin_web.md). Then use the File Restore wizard to restore files and folders of the file share.

1. [Launch the File Restore wizard](roll_back_to_point_in_time_launch_wizard_web.md).
2. [Select an object to restore](roll_back_to_point_in_time_backup_web.md).
3. [Finish working with the wizard](roll_back_to_point_in_time_summary_web.md).
