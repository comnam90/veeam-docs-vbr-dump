# Rolling Back to a Point in Time Using Web UI


Before you roll back the buckets or containers to a point in time, [check prerequisites](roll_back_bucket_to_point_web.md). Then use the Bucket rollback to a point in time wizard to restore buckets or containers.

1. [Launch the Bucket Rollback to a Point in Time wizard](roll_back_bucket_to_point_launch_web.md).
2. [Select buckets or containers to restore](roll_back_bucket_to_point_buckets_web.md).
3. [Finish working with the wizard](roll_back_bucket_to_point_summary_web.md).
