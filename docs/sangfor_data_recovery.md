# Performing Restore


In various disaster recovery scenarios, Veeam Backup & Replication allows you to perform the following operations using backed-up data:

* [Entire VM restore](sangfor_restore_entire_vm.md) — recover Sangfor aSV VMs to the original location or to a new location.

* [Disk publishing](sangfor_disk_publish.md) — mount specific disks of a backed-up Sangfor aSV VMs to any server added to the backup infrastructure.
* [File-level restore](sangfor_vm_guest_restore.md) — recover individual VM guest OS files and folders.
* [Application items restore](sangfor_restore_app_items.md) — restore applications, such as Microsoft Active Directory, Microsoft Exchange, Microsoft SharePoint and Microsoft SQL Server.

* [VM disk export](sangfor_disk_export.md) — restore VM disks and convert them to disks of the VMDK, VHD or VHDX format.
* [VM restore to Amazon Web Services](sangfor_restore_to_amazon_ec2.md) — restore Sangfor aSV VMs to Amazon Web Services as EC2 instances.
* [VM restore to Microsoft Azure](sangfor_restore_to_microsoft_azure.md) — restore Sangfor aSV VMs to Microsoft Azure as Azure VMs.
* [VM restore to Google Cloud](sangfor_restore_to_google.md) — restore Sangfor aSV VMs to Google Cloud as VM instances.

You can restore VM data to the most recent state or to any available restore point.
