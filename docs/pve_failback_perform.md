# Performing Failback


To perform failback for a VM replica, do the following:

1. [Launch the Failback wizard](pve_failback_perform_launch.md).
2. [Select replicas to fail back](pve_failback_perform_replicas.md).
3. [Specify the failback destination](pve_failback_perform_destination.md).
4. [Specify the target VM](pve_failback_perform_target_vm.md).
5. [Finish working with the wizard](pve_failback_perform_finish.md).
6. [Commit or undo failback](pve_failback_perform_finalize.md).
