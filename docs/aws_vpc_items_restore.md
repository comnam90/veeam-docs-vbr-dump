# Performing Selected Items Restore


In case of unexpected configuration changes, you can restore only specific items of the Amazon VPC configuration from a VPC configuration backup. Veeam Plug-in for AWS allows you to restore these items to the original location only.

To restore specific items of the VPC configuration, do the following:

1. [Launch the VPC Restore wizard](aws_restore_items_vpc_launch.md).
2. [Select a restore point and items to restore](aws_restore_items_vpc_point.md).
3. [Specify account settings for restore](aws_restore_entire_vpc_account.md).
4. [Specify a restore reason](aws_restore_items_vpc_reason.md).
5. [Finish working with the wizard](aws_restore_items_vpc_finish.md).
