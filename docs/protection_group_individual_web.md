# Creating Protection Group for Individual Computers Using Web UI


Before you create a protection group for individual computers, [check prerequisites](agents_protection_group_before_web.md). Then use the Add Protection Group wizard to configure a protection group.

1. [Launch the New Protection Group wizard](agents_protection_group_launch_web.md).
2. [Specify protection group name and description](agents_protection_group_name_web.md).
3. [Specify computers](agents_protection_group_computers_web.md).
4. [Specify discovery and deployment options](agents_protection_group_options_web.md).
5. [Specify advanced protection group settings](agents_protection_group_advanced_web.md).
6. [Review components](agents_protection_group_review_web.md).
7. [Finish working with the wizard](agents_protection_group_finish_web.md).
