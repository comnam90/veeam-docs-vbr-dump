# Step 4. Specify Advanced Settings


At the Storage Mapping step of the wizard, you can specify the following settings for the storage copy job:

* [Maintenance Settings](storage_copy_maintenance_settings.md)
* [Notification Settings](storage_copy_notification_settings.md)
* [Script Settings](storage_copy_script_settings.md)

|  |
| --- |
| Tip |
| After you specify necessary settings for the storage copy job, you can save them as default settings. To do this, click Save as Default at the bottom left corner of the Advanced Settings window. When you create a new storage copy job, Veeam Backup & Replication will automatically apply the default settings to the new job. |
