# Creating Job for Unix Computers


To back up data of a computer protected with Veeam Agent for IBM AIX or Veeam Agent for Oracle Solaris, you can configure a Veeam Agent backup job in Veeam Backup & Replication.

Before configuring a Veeam Agent backup job, [check prerequisites](agent_job_unix_before.md). Then use the New Agent Backup Job wizard to specify settings for the backup job.

1. [Launch the New Agent Backup Job wizard](agent_job_unix_launch.md)
2. [Select job mode](agent_job_unix_protection.md)
3. [Specify job name and description](agent_job_unix_name.md)
4. [Select computers to back up](agent_job_unix_machines.md)
5. [Select backup mode](agent_job_unix_mode.md)
6. [Specify backup scope settings](agent_job_unix_scope.md)
7. [Specify backup storage settings](agent_job_unix_target.md)
8. [Specify advanced backup settings](agent_job_unix_advanced.md)
9. [Specify the secondary target](agent_job_unix_secondary.md)
10. [Specify guest processing settings](agent_job_unix_guest.md)
11. [Specify the backup schedule](agent_job_unix_schedule.md)
12. [Review backup job settings](agent_job_unix_review.md)
