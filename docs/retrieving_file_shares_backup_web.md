# Retrieving File Shares Backup using Web UI


To start the retrieval of archived backup files, use the Retrieve Backup wizard.

1. [Launch Retrieve Backup wizard](file_share_retrieve_launch_web.md).
2. [Select Retrieval Mode](file_share_retrieve_mode_web.md).
3. [Select Availability Period](file_share_retrieve_period_web.md).
4. [Finish Working with the wizard](file_share_retrieve_summary_web.md).
