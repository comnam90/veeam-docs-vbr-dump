# Upgrading to Veeam Plug-in for Scale Computing HyperCore v4


You can upgrade Veeam Plug-in for Scale Computing HyperCore from version 1, 2 or 3 to version 4.

To upgrade Veeam Plug-in for Scale Computing HyperCore to version 4, do the following:

1. Upgrade your Veeam Backup & Replication server to version 13.1 as described in section [Upgrading to Veeam Backup & Replication 13](vbr_updating.md).
2. Complete the Components Update wizard as described in section [Server Components Upgrade](components_update.md).
