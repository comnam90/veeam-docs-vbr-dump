# Adding Configurations for Backup Account


By default, backup appliances deploy worker instances in the backup account to perform retention tasks, to execute EC2 backup and EC2 restore operations, and to create RDS archived backups. You can [choose an IAM role](aws_worker_role_backup.md) and [specify network settings](aws_worker_configurations_backup.md#region) that will be used to deploy these worker instances.
