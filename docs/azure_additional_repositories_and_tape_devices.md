# Additional Repositories and Tape Devices


Additional repositories and tape devices are any repositories where Veeam Backup & Replication keeps and stores copies of Azure VM backups. For more information, see [Backup Repository](backup_repository.md) and [Machines Backup to Tape](backup_to_tape_jobs.md).
