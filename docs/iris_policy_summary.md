# Step 8. Review Policy Settings


At the Summary step of the wizard, complete the configuration of the application backup policy.

1. Review the settings of the configured backup policy.
2. Select the Run the job when I click Finish check box if you want to enable the policy right after you close the wizard. After that, you can start the policy manually or wait for the scheduled start.
3. Click Finish to close the wizard.
