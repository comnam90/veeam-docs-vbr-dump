# Running Failover


In case a disaster strikes, you can switch operations from original VMs in the production site to their replicas in the disaster recovery site — this will allow users to keep accessing services with minimum disruption.

To fail over a VM to its replica, do the following:

1. [Launch the Failover wizard](pve_failover_run_launch.md).
2. [Select a restore point](pve_failover_run_vms.md).
3. [Specify the failover reason](pve_failover_run_reason.md).
4. [Finish working with the wizard](pve_failover_run_finish.md).
