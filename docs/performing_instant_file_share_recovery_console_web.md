# Performing Instant File Share Recovery Using Web UI


Before you perform instant file share recovery, [check prerequisites](instant_nas_recovery_byb_web.md). Then use the Instant File Share Recovery wizard.

1. [Launch the Instant File Share Recovery wizard](instant_nas_recovery_launch_web.md).
2. [Select a file share to restore](instant_nas_recovery_file_shares_web.md).
3. [Specify mount server settings](instant_nas_recovery_mount_servers_web.md).
4. [Specify file share access permissions](instant_nas_recovery_access_permissions_web.md).
5. [Specify a reason for instant recovery](instant_nas_recovery_reason_web.md).
6. [Finish working with the wizard](instant_nas_recovery_summary_web.md).
