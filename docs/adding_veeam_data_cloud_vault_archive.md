# Adding Veeam Data Cloud Vault Archive Using Web Ui


To add Veeam Data Cloud Vault Archive using the web UI, use the New Veeam Data Cloud Vault Archive wizard.

1. [Launch backup repository wizard](new_repository_veeam_data_cloud_web.md).
2. [Specify backup repository name](veeam_data_cloud_name_web.md).
3. [Specify Veeam account](veeam_data_cloud_account_web.md).
4. [Specify folder](veeam_data_cloud_folder_web.md).
5. [Specify mount server settings](veeam_data_cloud_mount_server_web.md).
6. [Finish working with wizard](veeam_data_cloud_finish_web.md).
