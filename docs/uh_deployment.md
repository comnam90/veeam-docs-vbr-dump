# Deployment


Starting from version 13.1, the Veeam Backup & Replication solution allows you to add universal hypervisor servers to the backup infrastructure, and to manage data protection and recovery operations for universal hypervisor workloads from a single console.

To access the plug-in functionality, you can either deploy a new backup server as described in section [Deployment](deployment.md) or use a backup server that already exists in your backup infrastructure if it meets the [Veeam Plug-in for Universal Hypervisor API system requirements](uh_system_requirements.md).
