# Adding IAM Roles


To add an IAM role to the backup appliance, do the following:

1. [Check prerequisites and limitations.](aws_byb_roles.md#byb)
2. [Launch the Add IAM Role wizard](aws_iam_roles_add_launch.md).
3. [Specify a name and description for the IAM role](aws_iam_roles_add_name.md).
4. [Specify IAM role settings](aws_iam_roles_add_settings.md).
5. [Specify IAM role permissions](aws_iam_roles_specify_permissions.md).
6. [Finish working with the wizard](aws_iam_roles_add_review.md).
