# Exporting Single Database


To export a single Microsoft SQL Server database files to a custom location, use the Export wizard.

1. [Launch the Export wizard](vesql_export_web_ui_mdf_single_wizard.md).
2. [Specify a restore point](vesql_export_web_ui_mdf_single_restore_point.md).
3. [Fine-tune the restore point](vesql_export_web_ui_mdf_single_fine_tune.md).
4. [Specify the target server](vesql_export_web_ui_mdf_single_target_server.md).
5. [Specify export location](vesql_export_web_ui_mdf_single_location.md).
6. [Review the export summary](vesql_export_web_ui_mdf_single_summary.md).
