# Adding Amazon S3 Object Storage, AWS Edition Storage Vaults, Amazon S3 Glacier Storage and AWS Snowball Edge


Before you add an Amazon S3 storage, AWS edition storage vault, Amazon Glacier or Amazon Snowball Edge to the backup infrastructure, check [prerequisites](s3_compatible_limitations.md) and [required permissions](permissions_object_storage.md#rpasos). If you plan to use immutability, verify that you have configured the [necessary settings](immutability_os_enable.md#S3) for your S3 buckets. After that, use the New Object Storage Repository wizard.
