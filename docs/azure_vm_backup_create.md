# Creating Schedule-Based VM Backup Policies


To create a schedule-based backup policy, do the following:

1. [Launch the Add VM Policy wizard](azure_vm_backup_wizard.md).
2. [Specify a backup policy name and description](azure_vm_backup_name.md).
3. [Configure backup source settings](azure_vm_backup_source_settings.md).
4. [Configure guest processing options](azure_vm_guest_processing.md).
5. [Configure backup target settings](azure_vm_backup_target_settings.md).
6. [Create a schedule for the backup policy](azure_vm_backup_policy_schedule.md).
7. [Specify automatic retry, health check and notification settings for the backup policy](azure_vm_backup_retry_notifications.md).
8. [Review the estimated cost of protecting the selected Azure VMs](azure_vm_backup_cost.md).
9. [Finish working with the wizard](azure_vm_backup_finish.md).
