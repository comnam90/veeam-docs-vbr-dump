# Adding XCP-ng Pool to Backup Infrastructure


To add an XCP-ng pool to the backup infrastructure, do the following:

1. [Launch New XCP-ng Pool Wizard](xen_xcp_server_add_launch.md)
2. [Specify the XCP-ng pool coordinator domain name or IP address](xen_xcp_server_add_name.md).
3. [Enter credentials to access the XCP-ng pool](xen_xcp_server_add_credentials.md).
4. [Apply XCP-ng pool settings](xen_xcp_server_add_apply.md).
5. [Finish working with the wizard](xen_xcp_server_add_summary.md).
