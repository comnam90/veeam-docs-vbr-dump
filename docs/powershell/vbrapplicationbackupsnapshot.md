# VBRApplicationBackupSnapshot


Contains information about an application backup snapshot.

VBRApplicationBackupSnapshot

| Property | Type | Description |
| Name | String | Specifies the name of the application backup snapshot. |
| RepositoryId | Guid | Specifies the ID of the application backup repository that contains the snapshot. |
| CreationTime | DateTime | Specifies the date and time when the snapshot was created. |
