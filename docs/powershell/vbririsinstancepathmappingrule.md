# VBRIrisInstancePathMappingRule


Contains a path mapping rule that maps an original path of an InterSystems IRIS instance to a target path.

VBRIrisInstancePathMappingRule

| Property | Type | Description |
| OriginalPath | String | Specifies the original path of the InterSystems IRIS instance data. |
| TargetPath | String | Specifies the target path to which the InterSystems IRIS instance data is restored. |
