# Configuring Veeam Software Appliance Event Forwarding


You can use the cmdlets in this topic to configure syslog event forwarding for the Veeam Software Appliance.

Configuring Veeam Software Appliance Event Forwarding

| Cmdlet | Operation |
| [Get-VBRVSAEventForwardingOptions](get-vbrvsaeventforwardingoptions.md) | Returns Veeam Software Appliance event forwarding settings. |
| [Set-VBRVSAEventForwardingOptions](set-vbrvsaeventforwardingoptions.md) | Modifies Veeam Software Appliance event forwarding settings. |
| [New-VBRVSAEventForwardingFilteringRule](new-vbrvsaeventforwardingfilteringrule.md) | Creates an advanced filtering rule for a specific application. |
| [Set-VBRVSAEventForwardingFilteringRule](set-vbrvsaeventforwardingfilteringrule.md) | Returns an updated copy of an advanced filtering rule. Use [Set-VBRVSAEventForwardingOptions](set-vbrvsaeventforwardingoptions.md) to persist the change. |
| [Export-VBRVSAEventForwardingFilteringRule](export-vbrvsaeventforwardingfilteringrule.md) | Exports advanced filtering rules to a file. |
| [Import-VBRVSAEventForwardingFilteringRule](import-vbrvsaeventforwardingfilteringrule.md) | Imports advanced filtering rules from a file. |
