# VBRIrisContainer


Contains a container of InterSystems IRIS servers for a protection group.

VBRIrisContainer

| Property | Type | Description |
| CustomCredentials | VBRIndividualComputerCustomCredentials[] | Specifies the credentials used to authenticate against the InterSystems IRIS servers in the container. |
