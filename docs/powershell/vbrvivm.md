# VBRViVM


Contains information about a VMware VM available on a vCenter Server.

Properties

Properties

| Property | Type | Description |
| Name | String | Name of the VM. |
| Reference | String | VMware managed object reference (MoRef) of the VM. |
| ServerId | Guid | ID of the vCenter Server on which the VM resides. |
