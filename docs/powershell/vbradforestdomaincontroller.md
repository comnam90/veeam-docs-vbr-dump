# VBRADForestDomainController


Contains a domain controller in a Microsoft Active Directory forest.

Properties

Properties

| Property | Type | Description |
| Fqdn | String | Fully qualified domain name (FQDN) of the domain controller. |
| IsReadonly | Bool | Indicates whether the domain controller is a read-only domain controller (RODC). |
