# Application Backup Repositories


You can use the cmdlets in this topic to perform the following operations.

Application Backup Repositories

| Cmdlet | Operation |
| [Add-VBRApplicationBackupRepository](add-vbrapplicationbackuprepository.md) | Adds application backup repositories. |
| [Get-VBRApplicationBackupRepository](get-vbrapplicationbackuprepository.md) | Returns connected application backup repositories. |
| [Set-VBRApplicationBackupRepository](set-vbrapplicationbackuprepository.md) | Modifies settings for application backup repositories. |
| [Remove-VBRApplicationBackupRepository](remove-vbrapplicationbackuprepository.md) | Removes application backup repositories from the backup infrastructure. |
| [New-VBRApplicationBackupRepositoryScheduleOptions](new-vbrapplicationbackuprepositoryscheduleoptions.md) | Creates snapshot scheduling options for application backup repositories. |
| [New-VBRApplicationBackupRepositoryPermission](new-vbrapplicationbackuprepositorypermission.md) | Creates host permissions for accessing the NFS share. |
| [New-VBRKerberosPermission](new-vbrkerberospermission.md) | Creates Kerberos permissions for accessing the NFS share. |
| [New-VBRApplicationBackupSnapshot](new-vbrapplicationbackupsnapshot.md) | Creates snapshots of the application backup repository volumes. |
| [Get-VBRApplicationBackupSnapshot](get-vbrapplicationbackupsnapshot.md) | Returns snapshots of the application backup repository volumes. |
| [Start-VBRApplicationBackupSnapshotInstantRecovery](start-vbrapplicationbackupsnapshotinstantrecovery.md) | Starts instant recovery from an application backup repository snapshot. |
| [Stop-VBRApplicationBackupSnapshotInstantRecovery](stop-vbrapplicationbackupsnapshotinstantrecovery.md) | Stops snapshot instant recovery session for an application backup repository. |
| [Start-VBRApplicationBackupSnapshotRecovery](start-vbrapplicationbackupsnapshotrecovery.md) | Starts recovery from an application backup repository snapshot. |
| [Start-VBRApplicationBackupCopyInstantRecovery](start-vbrapplicationbackupcopyinstantrecovery.md) | Starts instant recovery of the application backup repository data from a backup copy restore point. |
| [Start-VBRApplicationBackupRepositoryRescan](start-vbrapplicationbackuprepositoryrescan.md) | Rescans an application backup repository. |
