# VBREntraIDTenantItemExportMapping


Contains a restore point for Microsoft Entra ID item data that you plan to export.

Properties

Properties

| Property | Type | Description |
| Item | [VBREntraIDTenantItem](vbrentraidtenantitem.md) | Specifies the backed-up tenant item whose data you want to export. |
| RestorePoint | [VBREntraIDTenantRestorePoint](vbrentraidtenantrestorepoint.md) | Specifies a restore point from which you want to export the item data. |
