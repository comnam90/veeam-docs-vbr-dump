# VBRIrisProcessingOptions


Contains processing options for a discovered InterSystems IRIS instance.

VBRIrisProcessingOptions

| Property | Type | Description |
| BackupObject | Object | Specifies the discovered InterSystems IRIS instance for which the processing options are defined. |
| Username | String | Specifies the user name used to connect to the InterSystems IRIS instance during processing. |
