# Restoring Single Database


To restore a single database to an on-premise Microsoft SQL Server machine, use the Restore wizard.

1. [Launch the Restore wizard](vesql_restore_rds_single_tas_wizard.md).
2. [Specify a restore point](vesql_restore_rds_single_tas_specify_restore_point.md).
3. [Specify the target server](vesql_restore_rds_single_tas_specify_target_server.md).
4. [Specify files location](vesql_restore_rds_single_tas_specify_files_location.md).
5. [Specify the recovery state](vesql_restore_rds_single_tas_specify_recovery_state.md).
