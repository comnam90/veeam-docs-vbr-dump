# RDS Restore Using Web UI


Veeam Plug-in for AWS offers the following restore options:

* [RDS instance restore](aws_performing_rds_resource_restore.md) — restore an entire DB instance or an Aurora DB cluster from a restore point.
* [Database restore](aws_performing_rds_database_restore.md) — restore specific databases of Microsoft SQL Server and PostgreSQL DB instances.

You can restore RDS resource data to the most recent state or to any available restore point.
