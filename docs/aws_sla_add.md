# Adding SLA Templates


To add an SLA template, do the following:

1. [Launch the Add SLA Template wizard](aws_sla_add_launch.md)
   .
2. [Specify a template name and description](aws_sla_add_name.md)
   .
3. [Configure snapshot settings](aws_sla_add_snapshot_settings.md)
   .
4. [Configure backup settings](aws_sla_add_backup_settings.md)
   .
5. [Specify an SLA threshold and configure health check settings](aws_sla_add_general_settings.md)
   .
6. [Finish working with the wizard](aws_sla_add_finish.md)
   .
