# Overview


Starting from version 13.1, Veeam Backup & Replication comes with a plug-in that extends the solution functionality and allows you to add Sangfor aSV servers to the backup infrastructure, as well as to manage data protection and recovery operations for Sangfor aSV workloads from a single console.
