# Managing Workers Using Web UI


To protect Proxmox VE resources with Veeam Backup & Replication, you must configure at least one worker. However, it is recommended to deploy multiple workers to increase the maximum number of concurrent backup and restore operations.

After you add a Proxmox VE cluster to the backup infrastructure, you can manage workers directly from the [Veeam Backup & Replication web UI](web_ui_logon.md).
