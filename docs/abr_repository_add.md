# Adding Application Backup Repositories


This section describes how to add a Veeam Hardened Repository host as an application backup repository.

Before you begin, check [requirements and limitations](abr_limitations.md), and prepare a Linux server following the steps described in the [Deploying Application Backup Repository](deploy_abr.md) section.

To add a backup repository, use the New Application Backup Repository wizard.

1. [Launch the New Application Backup Repository wizard](abr_repository_launch.md).
2. [Specify backup repository name and description](abr_repository_name.md).
3. [Specify repository server](abr_repository_server.md).
4. [Configure repository settings and set access options](abr_repository_repository.md).
5. [Specify snapshot scheduling options](abr_repository_schedule.md).
6. [Review settings and components](abr_repository_review.md).
7. [Apply application backup repository settings](abr_repository_apply.md).
8. [Finish working with the wizard](abr_repository_summary.md).
