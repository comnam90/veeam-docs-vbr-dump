# Adding Universal Hypervisor Manager to Backup Infrastructure


To add a Universal Hypervisor Manager to the backup infrastructure, do the following:

1. [Launch the New Manager wizard](uh_server_add_launch.md).
2. [Specify the server domain name or IP address](uh_server_add_name.md).
3. [Enter credentials to access the server](uh_server_add_credentials.md).
4. [Apply Universal Hypervisor Manager settings](uh_server_add_apply.md).
5. [Finish working with the wizard](uh_server_add_summary.md).
