# Logs and Support


If you have any questions or issues with Epic EHR System Protection or Veeam Backup & Replication, you can search for a resolution on [Veeam R&D Forums](https://forums.veeam.com/) or submit a support case on the [Veeam Customer Support Portal](https://www.veeam.com/support.html).

When you submit a support case, attach a file containing logs related to Epic EHR System Protection operations.

Veeam Backup & Replication Logs

For details on how to collect Veeam Backup & Replication logs, see [Exporting Logs](exporting_logs.md).
