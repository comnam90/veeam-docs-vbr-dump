# Adding Workers


To deploy a worker and add it to the backup infrastructure, do the following:

1. [Check prerequisites and limitations](sangfor_workers_add_byb.md).
2. [Launch the New Sangfor aSV Worker wizard](sangfor_workers_add_launch.md).
3. [Specify worker VM configuration](sangfor_workers_add_vm.md).
4. [Specify worker network settings](sangfor_workers_add_network.md).
5. [Finish working with wizard](sangfor_workers_add_summary.md).
