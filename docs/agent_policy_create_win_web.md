# Creating Policy for Windows Computers Using Web UI


To back up data of a computer protected with Veeam Agent for Microsoft Windows, you can configure a Veeam Agent backup policy in Veeam Backup & Replication.

Before configuring a Veeam Agent backup policy, [check prerequisites](agent_policy_win_before_web.md). Then [launch the New Agent Backup Job wizard](agent_policy_win_launch_web.md), [select the type of protected computers and the job mode](agent_policy_win_protection_mode_web.md), and follow the wizard steps to define settings for the backup policy:

1. [Specify job name and description](agent_policy_win_name_web.md).
2. [Select computers to back up](agent_policy_win_scope_web.md).
3. [Select backup mode](agent_policy_win_mode_web.md).
4. [Specify backup scope](agent_policy_win_backup_scope_web.md).
5. [Select backup destination](agent_policy_win_destination_web.md).
6. [Specify backup storage settings](agent_policy_win_target_settings_web.md).
7. [Specify backup cache settings](agent_policy_win_cache_web.md).
8. [Specify guest processing settings](agent_policy_win_vss_web.md).
9. [Specify the backup schedule](agent_policy_win_schedule_web.md).
10. [Review backup job settings](agent_policy_win_review_web.md).
