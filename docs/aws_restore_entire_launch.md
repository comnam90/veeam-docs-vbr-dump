# Step 1. Launch Instance Restore Wizard


To launch the
Instance Restore
wizard, do the following.

1. Navigate to
   Protected Data
   >
    EC2
   .

1. Select the EC2 instance that you want to restore.
2. Click
   Restore
    >
   Instance Restore
   .

Alternatively, click the link in the
Restore Points
 column. Then, in the
Available Restore Points
 window, select the necessary restore point and click
Restore
 >
Instance Restore
.
