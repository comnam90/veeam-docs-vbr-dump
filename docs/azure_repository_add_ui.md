# Adding Backup Repositories Using Web UI


|  |
| --- |
| Important |
| If your backup appliance is managed by a Veeam Backup & Replication server and you add a new backup repository using the backup appliance Web UI, Veeam Plug-in for Microsoft Azure will not propagate these settings to the Veeam Backup & Replication server automatically. To discover new backup repositories created in the backup appliance, follow the instructions provided in section [Connecting to Existing Repositories](azure_repository_add_console_existing.md). |

To add a new backup repository, do the following:

1. [Launch the Add Repository wizard](azure_repository_ui_wizard.md).
2. [Specify a repository name and description](azure_repository_ui_name.md).
3. [Configure repository settings](azure_repository_ui_settings.md).
4. [Enable encryption for the backup repository](azure_repository_ui_encryption.md).
5. [Configure load control settings for the backup repository](azure_repository_ui_load.md).
6. [Finish working with the wizard](azure_repository_ui_finish.md).
