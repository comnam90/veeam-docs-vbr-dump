# Upgrading Plug-In


To upgrade
Veeam Plug-in for AWS
, do the following:

1. Install the new version of
   Veeam Plug-in for AWS
    as described in section
   [Deploying Plug-In](aws_installing_plugin.md)
   .
2. Upgrade backup appliances from the
   Veeam Backup & Replication
    console as described in section
   [Updating Appliances Using Console](aws_upgrade_appliance_console.md)
   .
