# Adding External Veeam Data Cloud Vault for Azure


To add an external Veeam Data Cloud Vault for Azure repository to the backup infrastructure, do the following:

1. [Launch the New External Repository wizard](add_data_cloud_vault_azure_launch.md).
2. [Specify the repository name](add_data_cloud_vault_azure_name.md).
3. [Choose storage vault](add_data_cloud_vault_azure_account.md).
4. [Choose target folder](add_data_cloud_vault_azure_container.md).
5. [Enable data encryption](add_data_cloud_vault_azure_encryption.md).
6. [Specify mount server settings](add_data_cloud_vault_azure_mount.md).
7. [Review properties and components](add_data_cloud_vault_azure_review.md).
8. [Apply settings](add_data_cloud_vault_azure_apply.md).
9. [Finish working with the wizard](add_data_cloud_vault_azure_summary.md).
