# Adding SMB File Share Using Web UI


Before you add an SMB file share to the inventory of the virtual infrastructure, consider the following:

* The file share meets requirements listed in the [Platform Support](https://helpcenter.veeam.com/docs/vbr/userguide/platform_support.html?ver=13#unstructured-data) section.

* If you plan to use a dedicated proxy server or cache repository, make sure these components are added in Backup Infrastructure.

To add an SMB file share as a source of unstructured data using web UI, do the following:

1. [Launch the New File Share wizard.](file_share_backup_smb_share_launch_wizard_web.md)
2. [Specify the path to the SMB file share and access credentials.](file_share_backup_smb_share_path_credentials_console.md)
3. [Specify file share processing settings.](file_share_backup_smb_share_processing_settings_web.md)
4. [Finish working with the wizard](file_share_backup_smb_share_summary_web.md)
