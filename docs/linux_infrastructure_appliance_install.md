# Installing Veeam Infrastructure Appliance with ISO


Before you configure a backup infrastructure component with Veeam Infrastructure Appliance, check the [prerequisites](linux_infrastructure_appliance_byb.md). Then, perform the following steps:

1. [Mount the ISO image](jeos_iso_install_mount.md).
2. [Select the deployment type](jeos_install_select_product.md).
3. [Begin installation](jeos_install_type.md).
4. [Read and accept license agreements](jeos_install_license.md).
5. [Select the appliance type](select_appliance_type.md).
6. [Specify the hostname](jeos_install_hostname.md).
7. [Review network settings](jeos_install_network.md).
8. [Review server time settings](jeos_install_time.md).
9. [Configure the default host administrator account](jeos_install_host_administrator.md).
10. [Configure the default security officer account](jeos_install_security_officer.md).
11. [Finish the configuration](jeos_install_summary.md).
