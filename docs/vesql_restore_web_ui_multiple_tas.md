# Restoring to Another Server


To restore multiple Microsoft SQL Server databases to another server, use the Restore wizard.

1. [Launch the Restore wizard](vesql_restore_web_ui_multiple_tas_wizard.md).
2. [Select databases you want to restore](vesql_restore_web_ui_multiple_tas_select_databases.md).
3. [Specify a restore point](vesql_restore_web_ui_multiple_tas_restore_point.md).
4. [Specify the target server](vesql_restore_web_ui_multiple_tas_target_server.md).
5. [Review the restore summary](vesql_restore_web_ui_multiple_tas_summary.md).
