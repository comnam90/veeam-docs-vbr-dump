# Creating FSx Backup Policies


To create a backup policy, do the following:

1. [Launch the Add FSx Policy wizard](aws_add_policy_launch_fsx.md)
   .
2. [Specify a backup policy name and description](aws_add_policy_name_fsx.md)
   .
3. [Specify a data protection scope](aws_add_policy_scope_fsx.md)
   .
4. [Configure backup source settings](aws_add_policy_source_settings_fsx.md)
   .
5. [Configure backup target settings](aws_add_policy_target_settings_backups_fsx.md)
   .
6. [Specify a schedule for the backup policy](aws_add_policy_schedule_retention_fsx.md)
   .
7. [Enable AWS tags assignment](aws_add_policy_target_settings_tags_fsx.md)
   .
8. [Configure automatic retry settings and notification settings for the backup policy](aws_add_policy_retry_notification_fsx.md)
   .
9. [Review estimated cost of the selected FSx file systems](aws_add_policy_cost_fsx.md)
   .
10. [Finish working with the wizard](aws_add_policy_finish_fsx.md)
    .
