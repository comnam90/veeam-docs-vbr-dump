# Launching Veeam Explorer Using Web UI


To restore application items from image-level backups, use the Application Item Restore wizard in the Veeam Backup & Replication web UI.

1. [Launch the wizard](restoring_veeam_explorers_launch_web_ui.md).
2. [Select a restore point](restoring_veeam_explorers_point_web_ui.md).
3. [Open Veeam Explorer](restoring_veeam_explorers_open_web_ui.md)
