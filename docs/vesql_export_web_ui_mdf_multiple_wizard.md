# Step 1. Launch Export Wizard


To launch the Export wizard, open the Browse tab and do the following:

1. In the navigation pane, select an instance or the server.
2. In the upper part of the preview pane, select Export > Export files.

Alternatively, you can open the Browse tab, right-click the instance or the server and select Export > Export files.
