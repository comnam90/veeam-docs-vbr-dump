# Configuring Roles Using Web UI


To configure a custom role in the Veeam Backup & Replication web UI, use the New Custom Role wizard and complete the following steps:

1. [Launch the Add New Role wizard](add_new_role_launch_web.md)
2. [Specify the role name and description](add_new_role_name_web.md)
3. [Define the inventory scope](add_new_role_inventory_scope_web.md)
4. [Define the repository scope](add_new_role_repository_scope_web.md)
5. [Configure the restore permissions](add_new_role_restore_permissions_web.md)
6. [Define the restore target scope](add_new_role_restore_target_scope_web.md)
7. [Finish working with the wizard](add_new_role_summary_web.md)
