# Step 1. Launch Instant Recovery Wizard


To launch the Instant Recovery wizard, open the Browse tab and do the following:

1. In the navigation pane, select an instance or the server.
2. In the upper part of the preview pane, select Instant Recovery > Recover point-in-time state to <original\_location>.

Alternatively, you can open the Browse tab, right-click an instance or the server and select Instant Recovery > Recover point-in-time state to <original\_location>.
