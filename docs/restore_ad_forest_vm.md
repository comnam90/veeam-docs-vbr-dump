# Restoring Active Directory Forest to VMware vSphere


To restore the Active Directory forest to VMware vSphere, do the following:

1. [Launch the Restore wizard](restore_ad_forest_wizard_vm.md)
2. [Specify the forest and point in time](restore_ad_forest_pit_vm.md)
3. [Specify restore points for authoritative domain controllers](restore_ad_forest_authoritative_dc_vm.md)
4. [Specify domain controller credentials](restore_ad_forest_dc_credentials_vm.md)
5. [Select target hosts](restore_ad_forest_hosts_vm.md)
6. [Select datastores](restore_ad_forest_datastores_vm.md)
7. [Select a folder](restore_ad_forest_folder_vm.md)
8. [Configure network mapping](restore_ad_forest_network_vm.md)
9. [Configure re-IP rules](restore_ad_forest_re_ip_vm.md)
10. [Finish working with the wizard](restore_ad_forest_review_vm.md)
