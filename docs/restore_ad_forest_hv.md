# Restoring Active Directory Forest to Microsoft Hyper-V


To restore the Active Directory forest to Microsoft Hyper-V, do the following:

1. [Launch the Restore wizard](restore_ad_forest_wizard_hv.md)
2. [Specify the forest and point in time](restore_ad_forest_pit_hv.md)
3. [Specify restore points for authoritative domain controllers](restore_ad_forest_authoritative_dc_hv.md)
4. [Specify domain controller credentials](restore_ad_forest_dc_credentials_hv.md)
5. [Select target hosts](restore_ad_forest_hosts_hv.md)
6. [Select datastores](restore_ad_forest_datastores_hv.md)
7. [Configure network mapping](restore_ad_forest_network_hv.md)
8. [Specify VM names and UUIDs](restore_ad_forest_name_hv.md)
9. [Configure re-IP rules](restore_ad_forest_re_ip_hv.md)
10. [Finish working with the wizard](restore_ad_forest_review_hv.md)
