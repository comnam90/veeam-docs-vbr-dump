# Adding SLA Templates


To add an SLA template, do the following:

1. [Launch the Add SLA Template wizard](azure_sla_wizard.md).
2. [Specify a template name and description](azure_sla_name.md).
3. [Configure snapshot settings](azure_sla_snapshot_settings.md).
4. [Configure backup settings](azure_sla_backup_settings.md).
5. [Specify an SLA threshold and configure health check settings](azure_sla_general_settings.md).
6. [Finish working with the wizard](azure_sla_finish.md).
