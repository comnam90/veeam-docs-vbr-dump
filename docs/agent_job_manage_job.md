# Managing Veeam Agent Backup Jobs


You can manage a Veeam Agent backup job managed by the backup server from the Veeam Backup & Replication console or the Veeam Backup & Replication web UI.

Using Veeam Backup & Replication Console

You can use the Veeam Backup & Replication console to perform the following operations with a Veeam Agent backup job:

* [Start and stop a Veeam Agent backup job](agent_job_start_stop.md).
* [Retry a Veeam Agent backup job](agent_job_retry.md).
* [Perform active full backup](agent_job_active_full.md).
* [Edit Veeam Agent backup job settings](agent_job_edit.md).
* [Enable and disable a Veeam Agent backup job](agent_job_edit.md).
* [Clone a Veeam Agent backup job](agent_job_clone.md).
* [Remove a Veeam Agent backup job](agent_job_delete.md).

Using Veeam Backup & Replication Web UI

You can use the Veeam Backup & Replication web UI to perform the same set of operations with a Veeam Agent backup job that protects Veeam Agent for Microsoft Windows or Veeam Agent for Linux computers. For an overview of what is and is not supported in the web UI, see [Working with Veeam Agent Backup Jobs and Policies](agents_management_interfaces.md#backup_jobs).
