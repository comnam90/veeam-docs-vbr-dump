# Configuring Veeam Plug-In for Xen


To start working with Veeam Plug-in for Xen, perform a number of steps for its configuration:

1. [Configure backup repositories](xen_configure_repository.md) where Veeam Backup & Replication will store backups of Xen VMs.
2. [Connect to the Citrix XenServer pool](xen_server_add.md) or [XCP-ng pool](xen_xcp_server_add.md) that administers resources you want to protect.
3. [Deploy workers](xen_workers.md) that will transfer backup traffic.
4. [[Optional] Configure email settings and notifications](xen_general_settings.md).
