# Adding Worker Profiles


To add a new custom set of worker profiles for one or more regions, do the following:

1. [Launch the Add Worker Profiles wizard](azure_worker_profile_wizard.md).
2. [Choose the necessary regions](azure_worker_profile_regions.md).
3. [Choose the profiles for worker instances in these regions](azure_worker_profile_selection.md).
4. [Finish working with the wizard](azure_worker_profile_finish.md).
