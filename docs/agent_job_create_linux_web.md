# Creating Job for Linux Computers Using Web UI


To back up data of a computer protected with Veeam Agent for Linux, you can configure a Veeam Agent backup job in Veeam Backup & Replication.

Before configuring a Veeam Agent backup job, [check prerequisites](agent_job_before_linux_web.md). Then [launch the New Agent Backup Job wizard](agent_job_launch_linux_web.md), [select the job mode](agent_job_protection_linux_web.md), and follow the wizard steps to define settings for the backup job:

1. [Specify job name and description](agent_job_name_linux_web.md).
2. [Select computers to back up](agent_job_comp_linux_web.md).
3. [Select backup mode](agent_job_mode_linux_web.md).
4. [Specify backup scope](agent_job_scope_linux_web.md).
5. [Specify backup storage settings](agent_job_target_set_linux_web.md).
6. [Specify guest processing settings](agent_job_guest_web.md).
7. [Specify the backup schedule](agent_job_schedule_linux_web.md).
8. [Review backup job settings](backup_job_review_linux_web.md).
