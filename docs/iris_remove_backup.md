# Removing Backups


In Veeam Backup & Replication, you can manage InterSystems IRIS instance application backup files in three ways. Each option handles the backup data differently.

You can remove application backups from Veeam Backup & Replication in the following ways:

* [Removing Backup from Backup Policy](iris_remove_backup_remove_from_policy.md)
* [Remove Backup from Configuration](iris_remove_backup_remove_from_configuration.md)
* [Delete Backup from Disk](iris_remove_backup_delete.md)
