# Instant Recovery of Latest State


To perform instant recovery of multiple databases to the latest state, use the Instant Recovery wizard.

1. [Launch the Instant Recovery wizard](vesql_ir_web_ui_multiple_latest_wizard.md).
2. [Select databases you want to recover](vesql_ir_web_ui_multiple_latest_select_databases.md).
3. [Specify switchover settings](vesql_ir_web_ui_multiple_latest_switchover_settings.md).
4. [Review the Instant Recovery summary](vesql_ir_web_ui_multiple_latest_summary.md).
5. [Finalize the Instant Recovery session](vesql_ir_web_ui_multiple_latest_finalize_ir_session.md).
