# Retrieving Objects Backups using Web UI


To start the retrieval of archived backup files, use the Retrieve Backup wizard.

1. [Launch Retrieve Backup wizard](step_1_launch_retrieve_backup_wizard_1.md).
2. [Select Retrieval Mode](step_2_specify_retrieval_mode_object.md).
3. [Select Availability Period](step_3_specify_availability_period_object.md).
4. [Finish Working with the wizard](step_4_finish_working_with_wizard_object.md).
