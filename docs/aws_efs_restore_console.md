# EFS Restore Using Console


Veeam Backup & Replication
offers the following restore operations:

* [File system restore](aws_restore_entire_efs_console.md)
   — restore an entire Amazon EFS file system.
* [File-level recovery](aws_restore_efs_files.md)
   — restore individual files and folders stored in a file system.

You can restore EFS file system data to the most recent state or to any available restore point.

|  |
| --- |
| Important |
| You can restore an EFS file system only to the same AWS account to which the source file system belongs. |
