# Veeam Plug-In Restore from Tape


You can restore Veeam Plug-In backup files from tape to a disk-based backup repository and continue the database recovery operations in the usual way.

There are two available scenarios for the Veeam Plug-In backup restore from tape:

* To restore the entire Veeam Plug-In backup, use the Restore Backup from Tape to Repository wizard. For more information, see [Restoring Backups from Tape to Repository](restoring_backups_from_tape.md).
* To restore a specific database, you can restore individual backup files to a repository. For details, see [Restoring Files from Tape](restore_files_from_tapes.md).

For more information, see the Backup to Tape section for specific Veeam Plug-Ins:

* [Veeam Plug-In for SAP on Oracle](https://helpcenter.veeam.com/docs/vbr/userguide/plugins_sap_orcl_backup_to_tape.html#how-restore-from-tape-works)
* [Veeam Plug-In for SAP MaxDB](https://helpcenter.veeam.com/docs/vbr/userguide/plugins_sap_maxdb_backup_to_tape.html#how-restore-from-tape-works)
