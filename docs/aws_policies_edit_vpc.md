# Editing VPC Configuration Backup Policy


To configure the VPC Configuration Backup policy settings, do the following:

1. [Launch the VPC Configuration Backup wizard](aws_vpc_policy_launch.md)
   .
2. [Select AWS Regions to protect](aws_vpc_policy_regions.md)
   .
3. [Specify a backup repository to store an additional backup copy](aws_vpc_policy_add_copy.md)
   .
4. [Configure retentions settings for VPC configuration backups](aws_vpc_policy_retention.md)
   .
5. [Specify notification settings for the backup policy](aws_vpc_policy_notification.md)
   .
6. [Finish working with the wizard](aws_vpc_policy_finish.md)
   .
