# Exporting Multiple Databases


To export multiple Microsoft SQL Server database files to a custom location, use the Export wizard.

1. [Launch the Export wizard](vesql_export_web_ui_mdf_multiple_wizard.md).
2. [Select databases you want to export](vesql_export_web_ui_mdf_multiple_select_databases.md).
3. [Specify a restore point](vesql_export_web_ui_mdf_multiple_restore_point.md).
4. [Specify the target server](vesql_export_web_ui_mdf_multiple_target_server.md).
5. [Specify export location](vesql_export_web_ui_mdf_multiple_location.md).
6. [Review the export summary](vesql_export_web_ui_mdf_multiple_summary.md).
