# Performing Disk Publish Using Web UI


Before you publish disks, [check prerequisites](integration_publish_before.md). Then use the Publish Disks wizard in the Veeam Backup & Replication web UI.

1. [Launch the wizard](integration_publish_wizard_web.md).
2. [Select a Veeam Agent computer whose disks you want to publish](integration_publish_computer_web.md).
3. [Select a restore point](integration_publish_point_web.md).
4. [Select disks](integration_publish_disk_web.md).
5. [Specify the target server](integration_publish_server_web.md).
6. [Specify a reason for disk publishing](integration_publish_reason_web.md).
7. [Finish working with the wizard](integration_publish_finish_web.md).
