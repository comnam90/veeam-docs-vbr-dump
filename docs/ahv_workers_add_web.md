# Adding Workers


To deploy a worker and add it to the backup infrastructure, do the following:

1. [Check prerequisites and limitations](ahv_workers_add_byb_web.md).
2. [Launch the Add Worker wizard](ahv_workers_add_launch_web.md).
3. [Specify worker name and descriptuin](ahv_workers_add_name_web.md).
4. [Specify worker VM settings](ahv_workers_add_vm_web.md).
5. [Configure network settings](ahv_workers_add_network_web.md).
6. [Finish working with wizard](ahv_workers_add_summary_web.md).
