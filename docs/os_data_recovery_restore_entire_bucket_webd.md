# Restoring Entire Bucket or Container Using Web Ui


Before you restore a bucket or container, [check prerequisites](restore_entire_bucket_byb_web.md). Then use the Bucket Restore wizard to restore the bucket or container.

1. [Launch the Bucket Restore wizard](restore_entire_bucket_launch_web.md).
2. [Select buckets or containers to restore](restore_entire_bucket_buckets_web.md).
3. [Specify a destination for the bucket or container restore](restore_entire_bucket_destination_web.md).
4. [Create a new bucket or container](restore_entire_bucket_new_bucket_web.md).
5. [Specify restore options](restore_entire_bucket_restore_options_web.md).
6. [Finish working with the wizard](restore_entire_bucket_summary_web.md).
