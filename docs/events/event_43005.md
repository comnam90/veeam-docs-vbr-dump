# High Availability Cluster Node Promoted


Sent when a secondary node is promoted to the primary node in the High Availability cluster. For more information, see [Failover](https://helpcenter.veeam.com/docs/vbr/userguide/high_availability_failover.html).

General Information

Event ID: 43005

Event message details: <SecondaryNodeName> cluster node has been promoted to primary.

Severity: Info

Parameters

Parameters

| Parameter Name | Description | Example |
| SecondaryNodeName | Secondary node name. Can be a DNS name or an IP address. | SecondaryNodeName="node02" |
| ClusterEndpoint | Cluster name. Can be a DNS name or an IP address. | ClusterEndpoint="198.51.100.15" |
| ClusterDescription | Cluster description. | ClusterDescription="ha-cluster" |
| VbrHostName | Backup server name. Can be a DNS name, an FQDN or an IP address. | VbrHostName="vbrsrv01.tech.local" |
| VbrVersion | Veeam Backup & Replication version. | VbrVersion="13.1.0.411" |
| Version | Event version (service parameter). | Version="1" |
| Description | Event message details. | Description="node02 cluster node has been promoted to primary." |
