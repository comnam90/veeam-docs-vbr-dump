# Remote Bare Metal Recovery Requested


Sent when a remote bare metal recovery request is created. For more information, see [Restoring from Veeam Recovery Media Remotely](https://helpcenter.veeam.com/docs/vbr/userguide/integration_instant_restore_media_remote.html).

General Information

Event ID: 44100

Event message details: A remote bare metal restore request has been received

Severity: Info

Parameters

Parameters

| Parameter Name | Description | Example |
| RequestID | Request ID. | RequestID="8f3c1d64-27ab-4e19-95d7-1c6b0af4e352" |
| SourceIpAddress | IP address from which the request was received. | SourceIpAddress="198.51.100.42" |
| ClientID | UUID of the target machine. | ClientID="b41e7f90-5c83-4d26-a7f1-9e2d38b0c645" |
| ExpirationTimeUtc | Date and time in UTC when the request expires. | ExpirationTimeUtc="07/26/2026 15:30:00" |
| ConnectionCode | Connection code used to pair the recovery environment with the backup server. | ConnectionCode="4816-2093" |
| LastKnownHostName | Name of the target machine. | LastKnownHostName="wks01.tech.local" |
| VbrHostName | Backup server name. Can be a DNS name, an FQDN or an IP address. | VbrHostName="vbrsrv01.tech.local" |
| VbrVersion | Veeam Backup & Replication version. | VbrVersion="13.1.0.411" |
| Version | Event version (service parameter). | Version="1" |
| Description | Event message details. | Description="A remote bare metal restore request has been received." |
