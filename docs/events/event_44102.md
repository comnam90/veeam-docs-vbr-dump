# Remote Bare Metal Recovery Finished


Sent when a remote bare metal recovery is finished. For more information, see [Restoring from Veeam Recovery Media Remotely](https://helpcenter.veeam.com/docs/vbr/userguide/integration_instant_restore_media_remote.html).

General Information

Event ID: 44102

Event message details: A remote bare metal restore session has been completed

Severity: Info, Warning, Error

Parameters
