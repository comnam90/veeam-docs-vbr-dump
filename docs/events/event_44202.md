# Entropy Analysis Results Downloaded


Sent when a user downloads entropy analysis results. For more information, see [Analyzing Encrypted Data Events](https://helpcenter.veeam.com/docs/vbr/userguide/malware_detection_analyze_encryption.html).

General Information

Event ID: 44202

Event message details: Entropy analysis result has been downloaded for backup <BackupName>

Severity: Info
