# Best Practice Suppressed


Sent when a user excludes one or more configuration parameters from the Security & Compliance Analyzer checklist. For more information, see [Security & Compliance Analyzer](https://helpcenter.veeam.com/docs/vbr/userguide/best_practices_analyzer.html).

General Information

Event ID: 42902

Event message details: Security & Compliance Analyzer validation <BestPracticeName> has been suppressed by <User> | <SuppressedCount> Security & Compliance Analyzer validations have been suppressed by <User>

Severity: Info

Parameters

Parameters

| Parameter Name | Description | Example |
| SuppressedCount | Number of configuration parameters excluded from the checklist. | SuppressedCount="1" |
| Note | Comment specified in the Note field. | Note="Remote Desktop Service is required" |
| ChangesXML | Updated data in the XML format. | ChangesXML="<Practices><BestPracticeInfo id="aeeed19c-b7c2-49cd-a24e-1254c8cc7045" type="227" status="3" note="HA cluster is not used." /></Practices>" |
| UserFullInfo | Detailed information about the user who performed an operation. Includes the following data:   * fullName — the user name * loginType | UserFullInfo="<ModifiedUserInfo fullName="TECH\user1" loginType="0" />" |
| VbrHostName | Backup server name. Can be a DNS name, an FQDN or an IP address. | VbrHostName="vbrsrv01.tech.local" |
| VbrVersion | Veeam Backup & Replication version. | VbrVersion="13.1.0.411" |
| Version | Event version (service parameter). | Version="1" |
| Description | Event message details. | Description="Security & Compliance Analyzer validation 'High Availability cluster should be configured for this backup server' has been suppressed by TECH\user1." |
