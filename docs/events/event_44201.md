# Entropy Analysis Session Finished


Sent when an entropy analysis session is finished. For more information, see [Analyzing Encrypted Data Events](https://helpcenter.veeam.com/docs/vbr/userguide/malware_detection_analyze_encryption.html).

General Information

Event ID: 44201

Event message details: Entropy analysis has finished with <Result> for backup <BackupName>

Severity: Info

Parameters

| Parameter Name | Description | Example |
| SessionID | Session ID. | SessionID="0ea5f2b5-a9d4-4431-aa8a-3c7717cfdf5a" |
| TargetEventID | Malware detection event ID. | TargetEventID="2cf4489b-8fe1-479b-bcc3-a673e9fedd13" |
| BackupName | Backup name. | BackupName="Backup Job 01" |
| BackupID | Backup ID. | BackupID="c58a3e17-9b42-4f06-8d51-7ae6b2019f34" |
| UserName | Name of the user who performed an operation. | UserName="TECH\user1" |
| UserID | SID of the user who performed the operation. | UserID="S-1-5-21-670747961-1840839389-3357612639-1134" |
| Result | Session result. Possible values:   * Success * Warning * Failed | Result="Success" |
| VbrHostName | Backup server name. Can be a DNS name, an FQDN or an IP address. | VbrHostName="vbrsrv01.tech.local" |
| VbrVersion | Veeam Backup & Replication version. | VbrVersion="13.1.0.411" |
| Version | Event version (service parameter). | Version="1" |
