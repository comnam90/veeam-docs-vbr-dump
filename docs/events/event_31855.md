# Encryption Password Assigned


Sent when a new encryption password is assigned to a backup by a user or a KMS server.

General Information

Event ID: 31855

Event message details: New encryption password has been assigned to the backup

Severity: Info

Parameters

Parameters

| Parameter Name | Description | Example |
| BackupId | Backup ID. | BackupId="7c9e4b21-3f5d-4a18-9c6e-2b8d51f0a374" |
| OriginalPasswordId | Previous password ID. | OriginalPasswordId="ad359169-b802-49ab-b3ea-b52d23461844" |
| OriginalPasswordHint | Previous password hint. | OriginalPasswordHint="Old encryption password" |
| NewPasswordId | New password ID. | NewPasswordId="5e1a7c38-9d4b-42f6-8a03-c7b6e2915d80" |
| NewPasswordHint | New password hint. | NewPasswordHint="New encryption password" |
| EncryptionType | Encryption type. Possible values:   * User * KMS | EncryptionType="User" |
| VbrHostName | Backup server name. Can be a DNS name, an FQDN or an IP address. | VbrHostName="vbrsrv01.tech.local" |
| VbrVersion | Veeam Backup & Replication version. | VbrVersion="13.1.0.411" |
| Version | Event version (service parameter). | Version="1" |
| Description | Event message details. | Description="New encryption password has been assigned to the backup." |
