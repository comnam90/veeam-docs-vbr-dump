# Adding General-Purpose Backup Proxies Using Console


You must add to the backup infrastructure one or more backup proxies that you plan to use for moving backup data in the unstructured data backup or Veeam Agent and storage system snapshot integration.

To add a backup proxy using Veeam Backup & Replication console:

1. [Launch the New Backup Proxy wizard](file_share_backup_new_file_proxy_launch_wizard.md).
2. [Choose a server](file_share_backup_new_file_proxy_choose_server.md).
3. [Configure traffic throttling rules](file_share_backup_new_file_proxy_traffic_rules.md).
4. [Review properties and components to install](file_share_backup_new_file_proxy_review.md).
5. [Apply backup proxy settings](file_share_backup_new_file_proxy_apply.md).
6. [Finish working with the wizard](file_share_backup_new_file_proxy_summary.md).
