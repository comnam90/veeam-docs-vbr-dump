# Retrieving File Shares Backup using Console


To start the retrieval of archived backup files, use the Retrieve Backup wizard.

1. [Launch Retrieve Backup wizard](file_share_retrieve_launch.md).
2. [Select Retrieval Mode](file_share_retrieve_mode.md).
3. [Select Availability Period](file_share_retrieve_period.md).
4. [Finish Working with the wizard](file_share_retrieve_summary.md).
