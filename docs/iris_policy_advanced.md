# Step 5. Specify Advanced Job Settings


In the Advanced job settings window, you can customize the following groups of options:

* [Storage](iris_policy_advanced_storage.md)
* [Maintenance](iris_policy_advanced_maintenance.md)
* [Scripts](iris_policy_advanced_scripts.md)
* [Notifications](iris_policy_advanced_notifications.md)

|  |
| --- |
| TIP |
| After you specify necessary settings for the application backup policy, you can save them as default settings. To do this, click Save as Default at the bottom left corner of the Advanced job settings window. When you create a new backup policy, Veeam Backup & Replication will automatically apply the default settings to the new policy. |
