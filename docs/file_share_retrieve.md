# Retrieving File Shares Backups


File backups that reside in an archive repository must be retrieved before you can restore data from them. Retrieval provides temporary access to the archived data. For more information, see [Data Retrieval](archive_tier_retrieval.md).

You can retrieve file share backups in one of the following ways:

* [Retrieve file share backups using console](retrieving_file_shares_backup_console.md).
* [Retrieve file share backups using web UI](retrieving_file_shares_backup_web.md).
