# /nas/backupSessions


Represents a list of all file share backup job sessions performed on all backup servers connected to Veeam Backup Enterprise Manager.

Resource URL

|  |
| --- |
| https://<Enterprise-Manager>:9398/api/nas/backupSessions |

Related Resources

[backupSessions/{ID}](backupsessions_id.md)

Methods

The following methods are supported for the /nas/backupSessions resource:

[GET /nas/backupSessions](get_nas_backupsessions.md)
