# /agents/restorePoints


Represents a collection of restore points for backups created by Veeam Agent managed by Veeam Backup & Replication. Backups are created on or imported to backup servers connected to Veeam Backup Enterprise Manager.

Resource URL

|  |
| --- |
| https://<Enterprise-Manager>:9398/api/agents/restorePoints |

Related Resources

[/restorePoints/{ID}](restorepoints_id.md)

Methods

The following methods are supported for the /agents/restorePoints resource:

[GET /agents/restorePoints](get_agents_restorepoints.md)
