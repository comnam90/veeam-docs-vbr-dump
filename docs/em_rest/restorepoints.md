# /restorePoints


Represents a collection of all restore points for backups and replicas created on or imported to backup servers connected to Veeam Backup Enterprise Manager.

Resource URL

|  |
| --- |
| https://<Enterprise-Manager>:9398/api/restorePoints |

Related Resources

[/restorepoints/{ID}](restorepoints_id.md)

Methods

The following methods are supported for the /restorePoints resource:

[GET /restorepoints](get_restorepoints.md)
