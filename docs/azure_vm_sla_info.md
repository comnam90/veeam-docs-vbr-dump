# Step 2. Specify Policy Name


At the Policy Info step of the wizard, enter a name for the new policy and provide a description for future reference. The maximum length of the name is 255 characters. The following characters are not supported: / \ " ' : | < > + = ; , ? ! \* % # ^ @ & $ .
