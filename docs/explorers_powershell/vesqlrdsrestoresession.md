# VESQLRDSRestoreSession


Contains details about a Veeam Explorer for Microsoft SQL Server restore session started to explore and restore backed-up Microsoft SQL Server databases running on Amazon RDS.

VESQLRDSRestoreSession

| Property | Type | Description |
| Id | GUID | Restore session ID. |
| StartTime | DateTime | Date and time when the restore session was started. |
