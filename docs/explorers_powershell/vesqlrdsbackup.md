# VESQLRDSBackup


Contains details about backups Amazon RDS instances for Microsoft SQL Server.

VESQLRDSBackup

| Property | Type | Description |
| Id | GUID | Backup ID. |
| Name | String | Backup name. |
| ServerName | String | DNS name or IP address of the source server. |
