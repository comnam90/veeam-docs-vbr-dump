# Performing Instant Application Backup Repository Recovery


You can revert the application backup repository data to a point in time using snapshots or export the data for browsing and selective restore.

Before you perform instant application backup repository recovery, check [considerations and limitations](abr_limitations.md). Then use the Instant Application Backup Repository Recovery wizard.

1. [Launch the Instant Application Backup Repository Recovery wizard](instant_abr_recovery_launch.md).
2. [Select a restore point](instant_abr_recovery_restore_point.md).
3. [Select a restore mode](instant_abr_recovery_mode.md).
4. [Specify a destination for repository data](instant_abr_recovery_destination.md).
5. [Specify access permissions](instant_abr_recovery_permissions.md).
6. [Specify a restore reason](instant_abr_recovery_reason.md).
7. [Review Instant Recovery settings](instant_abr_recovery_summary.md).
8. [Finalize Instant Recovery](instant_abr_recovery_finalize.md).
