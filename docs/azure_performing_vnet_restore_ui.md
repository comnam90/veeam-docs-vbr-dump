# Performing Virtual Network Configuration Restore Using Web UI


Veeam Plug-in for Microsoft Azure offers the following disaster recovery operations:

* [Full restore](azure_entire_vnet_restore_hiw.md) — restores the entire virtual network configuration.
* [Granular restore](azure_granular_vnet_restore_hiw.md) — restores the selected virtual network configuration items.

You can restore the virtual network configuration data to the most recent state or to any available restore point.
