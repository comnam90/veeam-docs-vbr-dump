# Instant Recovery to Another Server


To perform instant recovery of a database to another server, use the Instant Recovery wizard.

1. [Launch the Instant Recovery wizard](vesql_ir_web_ui_single_tas_wizard.md).
2. [Specify a restore point](vesql_ir_web_ui_single_tas_restore_point.md).
3. [Fine-tune the restore point](vesql_ir_web_ui_single_tas_fine_tune.md).
4. [Specify the target server](vesql_ir_web_ui_single_tas_target_server.md).
5. [Specify database files location](vesql_ir_web_ui_single_tas_location.md).
6. [Specify switchover settings](vesql_ir_web_ui_single_tas_switchover_settings.md).
7. [Review the Instant Recovery summary](vesql_ir_web_ui_single_tas_summary.md).
8. [Finalize the Instant Recovery session](vesql_ir_web_ui_single_tas_finalize_ir_session.md).
