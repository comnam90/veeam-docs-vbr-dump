# Sangfor aSV


Veeam Backup & Replication offers various data protection and disaster recovery features for Sangfor aSV. Specifically, you can perform the following operations:

* Create backups of Sangfor aSV VMs and store them in backup repositories.

* Create VeeamZIP backups of Sangfor aSV VMs.

* Create several instances (copies) of the same backup data in different locations.
* Restore VMs from Sangfor aSV VM backups to the Sangfor aSV environment.

* Restore VMs from VMware ESXi and Microsoft Hyper-V to the Sangfor aSV environment.
* Restore VMs from Nutanix AHV, Proxmox VE, oVirt KVM, Scale Computing HyperCore, Xen, HPE Morpheus VM Essentials backups to the Sangfor aSV environment.

* Restore VMs from Microsoft Azure, Amazon Web Services (AWS) and Google Cloud backups to the Sangfor aSV environment.
* Restore physical machines from backups created by Veeam Agents to the Sangfor aSV environment.

* Restore VMs from Sangfor aSV backups to Microsoft Azure, Amazon Web Services (AWS) and Google Cloud environments.
* Restore VMs from Sangfor aSV backups to Nutanix AHV, Proxmox VE, oVirt KVM, Scale Computing HyperCore, Xen, HPE Morpheus VM Essentials environments.
* Perform Instant Recovery of Sangfor aSV VMs to VMware vSphere and Microsoft Hyper-V environments.
* Restore application items (such as Microsoft Active Directory, Microsoft Exchange, Microsoft SharePoint, Microsoft DNS, PostgreSQL, Oracle Database and Microsoft SQL Server).
* Restore files and folders of Sangfor aSV VM guest OSes.
* Export disks of backed-up Sangfor aSV VMs to VMDK, VHD and VHDX formats.
* Mount disks of backed-up Sangfor aSV VMs to any server and access data in the read-only mode.
