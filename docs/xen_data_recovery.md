# Performing Restore


In various disaster recovery scenarios, Veeam Backup & Replication allows you to perform the following operations using backed-up data:

* [Entire VM restore](xen_restore_entire_vm.md) — recover Xen VMs to the original location or to a new location.
* [Instant VM recovery](xen_restore_instant.md) — instantly start a Xen VM directly from a backup.
* [Disk publishing](xen_disk_publish.md) — mount specific disks of a backed-up Xen VMs to any server added to the backup infrastructure.
* [File-level restore](xen_vm_guest_restore.md) — recover individual VM guest OS files and folders.

* [VM disk export](xen_disk_export.md) — restore VM disks and convert them to disks of the VMDK, VHD or VHDX format.
* [VM restore to Amazon Web Services](xen_restore_to_amazon_ec2.md) — restore Xen VMs to Amazon Web Services as EC2 instances.
* [VM restore to Microsoft Azure](xen_restore_to_microsoft_azure.md) — restore Xen VMs to Microsoft Azure as Azure VMs.
* [VM restore to Google Cloud](xen_restore_to_google.md) — restore Xen VMs to Google Cloud as VM instances.

You can restore VM data to the most recent state or to any available restore point.
