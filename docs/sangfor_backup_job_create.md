# Creating Backup Jobs


To create a backup job, do the following:

1. [Check prerequisites and limitations](sangfor_backup_job_create_prerequisites.md).
2. [Launch the New Backup Job wizard](sangfor_backup_job_create_launch.md).
3. [Specify a job name and description](sangfor_backup_job_create_general_settings.md).
4. [Select VMs to back up](sangfor_backup_job_create_assign_vms.md).
5. [Specify a backup repository and configure backup settings](sangfor_backup_job_create_destination.md).
6. [Create a schedule for the backup job](sangfor_backup_job_create_schedule.md).
7. [Finish working with the wizard](sangfor_backup_job_create_summary.md).
