# XCP-ng and Citrix XenServer


Veeam Backup & Replication offers various data protection and disaster recovery features for Xen environments. Specifically, you can perform the following operations:

* Create backups of Xen VMs and store them in backup repositories.

* Create VeeamZIP backups of Xen VMs.

* Create several instances (copies) of the same backup data in different locations.
* Restore VMs from Xen VM backups to the Xen environment.

* Restore VMs from VMware ESXi and Microsoft Hyper-V to the Xen environment.
* Restore VMs from Nutanix AHV, oVirt KVM, Scale Computing HyperCore, Proxmox VE, HPE Morpheus VM Essentials, Sangfor aSV backups to the Xen environment.

* Restore VMs from Microsoft Azure, Amazon Web Services (AWS) and Google Cloud backups to the Xen environment.
* Restore physical machines from backups created by Veeam Agents to the Xen environment.

* Restore VMs from Xen backups to Microsoft Azure, Amazon Web Services (AWS) and Google Cloud environments.
* Restore VMs from Xen backups to Nutanix AHV, oVirt KVM, Scale Computing HyperCore, Proxmox VE, HPE Morpheus VM Essentials, Sangfor aSV environments.
* Perform Instant Recovery of Xen VMs to VMware vSphere, Microsoft Hyper-V, Nutanix AHV and Proxmox VE environments.

* Restore files and folders of Xen VM guest OSes.
* Export disks of backed-up Xen VMs to VMDK, VHD and VHDX formats.
* Mount disks of backed-up Xen VMs to any server and access data in the read-only mode.
