# Deployment


Starting from version 13.1, the Veeam Backup & Replication solution allows you to add Xen pools to the backup infrastructure, and to manage data protection and recovery operations for Xen workloads from a single console.

To access the plug-in functionality, you can either deploy a new backup server as described in section [Deployment](deployment.md) or use a backup server that already exists in your backup infrastructure if it meets the [Veeam Plug-in for Xen system requirements](xen_system_requirements.md).
