# Retrieving Objects Backups


Object backups that reside in an archive repository must be retrieved before you can restore data from them. Retrieval provides temporary access to the archived data. For more information, see [Data Retrieval](archive_tier_retrieval.md).

You can retrieve object backups in one of the following ways:

* [Retrieve object backups using console](retrieving_objects_backups_using_console.md).
* [Retrieve object backups using web UI](retrieving_objects_backups_using_web_ui.md).
