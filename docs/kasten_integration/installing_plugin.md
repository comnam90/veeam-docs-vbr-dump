# Installing Plug-In


Veeam Plug-in for Kasten is automatically installed while you install or upgrade Veeam Backup & Replication to the [required version](system_requirements.md#vbr). For more information, see the [Installing Veeam Backup & Replication on Microsoft Windows](https://helpcenter.veeam.com/docs/vbr/userguide/install_vbr.html?ver=13) and [Upgrading to Veeam Backup & Replication 13 on Windows](https://helpcenter.veeam.com/docs/vbr/userguide/upgrade_vbr.html?ver=13) sections in the Veeam Backup & Replication User Guide.
