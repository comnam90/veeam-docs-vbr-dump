# Viewing Real-Time Statistics


You can use the Veeam Backup & Replication console to view real-time statistics for any backup policy. For more information on how to review statistics, see [Reporting](https://helpcenter.veeam.com/docs/vbr/userguide/reporting.html?ver=13) section in the Veeam Backup & Replication User Guide.
