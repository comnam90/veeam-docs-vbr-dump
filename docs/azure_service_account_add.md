# Adding Service Accounts


To add a new service account, do the following:

1. [Launch the Add Account wizard](azure_service_account_wizard.md).
2. [Specify an account name and description](azure_service_account_name.md).
3. [Choose an account type](azure_service_account_type.md).
4. [Choose a scope for the account](azure_service_account_scope.md).
5. [Specify account roles](azure_service_account_select_roles.md).
6. [Check the required permissions](azure_service_account_check_permissions.md).
7. [Finish working with the wizard](azure_service_account_finish.md).
