# Adding Worker Configurations


To add a new worker configuration, do the following:

1. [Launch the Add Worker Network Configuration wizard](azure_worker_configuration_wizard.md).
2. [Specify general settings for the worker configuration](azure_worker_configuration_general.md).
3. [Specify network settings for the worker configuration](azure_worker_configuration_network.md).
4. [Finish working with the wizard](azure_worker_configuration_finish.md).
