# Restoring Specific Files and Folders Using Web UI


Before you restore specific files and folders, [check prerequisites](restore_files_folders_before_you_begin_web.md). Then use the File Restore wizard to restore files and folders of the file share.

1. [Launch the File Restore wizard](restore_files_folders_launch_wizard_web.md).
2. [Select files and folders to restore](restore_files_folders_backup_browser_web.md).
3. [Select restore mode](restore_files_folders_restore_mode_web.md).
4. [Select a restore point](restore_files_folders_restore_point_web.md).
5. [Select a file version to restore.](restore_files_folders_file_version_web.md)
6. [Specify the destination for file restore.](restore_files_folders_destination_web.md)
7. [Finish working with the wizard](restore_files_folders_summary2_web.md).
