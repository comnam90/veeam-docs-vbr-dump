# Launching Application and Exploring Backups


To open the Veeam Explorer for Microsoft Active Directory web UI and load Active Directory data from a restore point created by Veeam Backup & Replication, use the Restore application item option.

For more information, see [Launching Veeam Explorer Using Web UI](restoring_veeam_explorers_web_ui.md).
