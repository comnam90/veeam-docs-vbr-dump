# Step 1. Launch Restore Wizard


To launch the Restore wizard, open the Browse tab and do the following:

1. In the navigation pane, select a container.
2. In the upper part of the navigation pane, select Restore > Restore container to.

Alternatively, you can open the Browse tab, right-click the container and select Restore > Restore container to.
