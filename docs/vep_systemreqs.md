# System Requirements


This section lists system requirements for Veeam Explorer for PostgreSQL.

System Requirements

| Component | Requirement |
| PostgreSQL | Veeam Explorer for PostgreSQL supports restore of the following PostgreSQL versions on Windows and Linux machines:  * PostgreSQL 18 * PostgreSQL 17 * PostgreSQL 16 * PostgreSQL 15 * PostgreSQL 14 |
