# Creating SLA-Based VM Backup Policies


To create an SLA-based backup policy, do the following:

1. [Launch the Add SLA-Based Policy wizard](azure_vm_sla_wizard.md).
2. [Specify a policy name and description](azure_vm_sla_info.md).
3. [Configure backup source settings](azure_vm_sla_source_settings.md).
4. [Configure guest processing options](azure_vm_sla_guest_processing.md).
5. [Configure protection settings](azure_vm_sla_storage_settings.md).
6. [Configure tag settings](azure_vm_sla_tags_snapshot_location.md).
7. [Specify general settings for the policy](azure_vm_sla_notifications.md).
8. [Review the estimated cost of protecting the selected Azure VMs](azure_vm_sla_cost.md).
9. [Finish working with the wizard](azure_vm_sla_finish.md).
