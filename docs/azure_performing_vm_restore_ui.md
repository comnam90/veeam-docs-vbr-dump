# Performing VM Restore Using Web UI


Veeam Plug-in for Microsoft Azure offers the following restore options:

* [VM Restore](azure_entire_vm_restore_ui.md) — restores an entire Azure VM.
* [Disk Restore](azure_performing_disk_restore.md) — restores virtual disks attached to an Azure VM.
* [File-level Restore](azure_performing_flr.md) — restores individual files and folders of an Azure VM.

You can restore Azure VM data to the most recent state or to any available restore point.
