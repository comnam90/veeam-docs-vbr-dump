# Restoring Individual Objects or Versions Using Web UI


Before you restore specific objects, [check prerequisites](restore_individual_objects_byb_web.md). Then use the Objects or Versions Restore wizard to restore objects or their specific versions.

1. [Launch the Objects or Versions Restore wizard](restore_individual_objects_launch_web.md).
2. [Select objects to restore](restore_individual_objects_browser_web.md).
3. [Select a restore mode](restore_individual_objects_restore_mode_web.md).
4. [Select a restore point](restore_individual_objects_restore_point_web.md).
5. [Select an object version to restore](restore_individual_objects_object_version_web.md).
6. [Specify the destination for object restore](restore_individual_objects_destination_web.md).
7. [Finish working with the wizard](restore_individual_objects_summary_finish_web.md).
