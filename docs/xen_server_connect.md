# Connecting Xen Pool


A Xen pool (XCP-ng pool or Citrix XenServer pool) allows the backup server to access resources such as VMs, storage and networks. After you add an XCP-ng pool or Citrix XenServer pool to the backup infrastructure, you will be able to deploy workers and to manage data protection tasks for Xen VMs.
