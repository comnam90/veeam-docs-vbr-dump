# Performing File-Level Recovery


In case a disaster strikes, you can recover corrupted or missing files of an Azure VM from a cloud-native snapshot or image-level backup. Veeam Backup for Microsoft Azure allows you to download the necessary files and folders to a local machine, or restore the files and folders of the source Azure VM to the original location, using the [File-level recovery browser](azure_flr_download.md).

To recover files and folders of a protected Azure VM, do the following:

1. [Launch the File-Level Recovery wizard](azure_flr_wizard.md).
2. [Select a restore point](azure_flr_restore_point.md).
3. [Configure restore settings](azure_flr_restore_settings.md).
4. [Specify a restore reason](azure_flr_reason.md).
5. [Finish working with the wizard — start a recovery session](azure_flr_restore_session.md).
6. [Choose files and folders to recover](azure_flr_download.md).
7. [Stop the recovery session](azure_flr_stop_session.md).
