# Creating Application Backup Policy


To create a new InterSystems IRIS application backup policy, launch the New Application Backup Policy wizard and complete the steps below. A policy can run in backup mode, which copies instance data to a backup repository, or in snapshot-only mode, which retains only storage snapshots on the storage system. You select the mode when you specify the target at the [Specify Storage Settings](iris_policy_storage.md) step.
