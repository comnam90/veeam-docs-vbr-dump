# Creating IAM Role Templates


To create an IAM role template, do the following:

1. [Launch the Create IAM Role Template wizard](aws_iam_template_add_launch.md)
   .
2. [Specify a name and template format for the IAM role](aws_iam_template_add_name.md)
   .
3. [Specify IAM role permissions](aws_iam_template_specify_permissions.md)
   .
4. [Finish working with the wizard](aws_iam_template_add_review.md)
   .
