# oVirt KVM


Veeam Backup & Replication offers various data protection and disaster recovery features for oVirt KVM environments. Specifically, you can perform the following operations:

* Create backups of oVirt VMs and store them in backup repositories.
* Create VeeamZIP backups of oVirt KVM VMs.
* Create several instances (copies) of the same backed-up data in different locations.
* Restore VMs from oVirt KVM backups to oVirt KVM environments.
* Restore VMs from VMware ESXi and Microsoft Hyper-V to the oVirt KVM environment.

* Restore VMs from Nutanix AHV, HPE Morpheus VM Essentials, oVirt KVM, Proxmox VE, Sangfor aSV, Scale Computing HyperCore, XCP-ng and Citrix XenServer backups to the oVirt KVM environment.

* Restore VMs from backups produced by Veeam Plug-in for Universal Hypervisor API to the oVirt KVM environment.

* Restore VMs from Microsoft Azure, Amazon Web Services (AWS) and Google Cloud backups to the oVirt KVM environment.
* Restore physical machines from backups created by Veeam Agents to the oVirt KVM environment.

* Restore VMs from oVirt KVM backups to Microsoft Azure, Amazon Web Services (AWS) and Google Cloud environments.
* Restore VMs from oVirt KVM backups to VMware vSphere and Microsoft Hyper-V environments.

* Restore VMs from oVirt KVM backups to Nutanix AHV, HPE Morpheus VM Essentials, Proxmox VE, Sangfor aSV, Scale Computing HyperCore, XCP-ng, Citrix XenServer environments and universal hypervisors.

* Perform Instant Recovery of VMs and physical machines to VMware vSphere, Microsoft Hyper-V, Nutanix AHV and Proxmox VE environments.

* Restore files and folders of oVirt KVM VM guest OSes.
* Restore application items (such as Microsoft Active Directory, Microsoft Exchange, Microsoft SharePoint, PostgreSQL, Oracle Database and Microsoft SQL Server).
* Restore VM disks and attach them to VMs running on oVirt KVM hosts.
* Export disks of backed-up oVirt VMs to VMDK, VHD and VHDX formats.

* Mount disks of backed-up oVirt VMs to any server and access data in the read-only mode.
