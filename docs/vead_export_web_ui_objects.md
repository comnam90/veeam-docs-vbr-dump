# Exporting Objects


To export objects in the Veeam Explorer for Microsoft Active Directory web UI, do the following:

1. [Launch the Export wizard](vead_export_web_ui_objects_wizard.md).
2. [Specify the target server](vead_export_web_ui_objects_server.md).
3. [Specify the export location](vead_export_web_ui_objects_location.md).
4. [Review the export summary](vead_export_web_ui_objects_summary.md).
