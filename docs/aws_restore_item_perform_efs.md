# Performing File-Level Restore


In case a disaster strikes, you can recover corrupted or missing files of an EFS file system from an EFS backup or backup copy. Veeam Plug-in for AWS allows you to restore files and folders to the original file system or to another file system.

To recover files and folders of a protected file system, do the following:

1. [Launch the EFS File-level Recovery wizard](aws_restore_item_launch_efs.md).
2. [Choose a restore type](aws_restore_item_type_efs.md).
3. [Configure restore settings](aws_restore_item_settings_efs.md).
4. [Specify account settings for restore](aws_restore_item_account_efs.md).
5. [Choose a restore mode](aws_restore_item_mode_efs.md).
6. [Specify a restore reason](aws_restore_item_reason_efs.md).
7. [Finish working with the wizard](aws_restore_item_finish_efs.md).
8. [Open the file-level recovery browser](aws_restore_item_session_efs.md).
9. [Select a restore point](aws_restore_item_restore_point_efs.md).
10. [Choose files and folders to recover](aws_restore_item_save_efs.md).
11. [Stop the recovery session](aws_restore_item_stop_efs.md).
