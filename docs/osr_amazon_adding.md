# Adding Amazon S3 Storage and AWS Edition Storage Vaults


This section describes how to add Amazon S3 object storage and AWS edition storage vault to the backup infrastructure.

For more information about Amazon S3 object storage, see [AWS Documentation](https://aws.amazon.com/s3/?sc_channel=PS&sc_campaign=acquisition_RU&sc_publisher=google&sc_medium=ACQ-P%7CPS-GO%7CBrand%7CDesktop%7CSU%7CStorage%7CS3%7CRU%7CEN%7CText&sc_content=s3_e&sc_detail=amazon%20s3&sc_category=Storage&sc_segment=293618441715&sc_matchtype=e&sc_country=RU&s_kwcid=AL!4422!3!293618441715!e!!g!!amazon%20s3&ef_id=EAIaIQobChMI19fJ5IP75AIVQeWaCh0lyAGdEAAYASAAEgIHnPD_BwE:G:s).

For more information about AWS edition storage vault, see the [Veeam Data Cloud Vault Editions](https://helpcenter.veeam.com/docs/vdc/userguide/vault_editions.html) section of the Veeam Data Cloud User Guide.

To add Amazon S3 object storage and AWS edition storage vault, use the New Object Storage Repository wizard.

1. [Launch New Object Repository Wizard](new_object_repository_amazon.md).
2. [Specify object storage name](amazon_repository_name.md).
3. [Specify object storage account](amazon_repository_account.md).
4. [Specify object storage settings](amazon_storage_details.md).
5. [Specify mount server settings](amazon_storage_mount_server.md).
6. [Review components](amazon_storage_mount_review.md).
7. [Apply settings](amazon_storage_apply.md).
8. [Finish working with the wizard](amazon_finishing_wizard.md).
