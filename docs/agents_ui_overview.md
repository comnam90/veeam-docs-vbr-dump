# Getting to Know Veeam Agent Management Interfaces


You can manage Veeam Agents in Veeam Backup & Replication in both available interfaces:

* [Veeam Backup & Replication console](#console)
* [Veeam Backup & Replication web UI](#webui)

Using Veeam Backup & Replication Console

In the [Veeam Backup & Replication console](vbr_ui.md), you can perform most Veeam Agent management operations, except for:

* [Enabling remote bare metal recovery for protected computers](agents_protection_group_advanced_vaw_web.md)
* [Customizing the Veeam Agent Control Panel](agents_protection_group_customize.md)

To perform these operations, use the Veeam Backup & Replication web UI.

Using Veeam Backup & Replication Web UI

In the [Veeam Backup & Replication web UI](vbr_web_console.md), you can perform key Veeam Agent management operations, such as creating and managing protection groups, backup jobs and backup policies, as well as performing restore.

To learn more, see [Veeam Agent Web UI Features](agents_management_interfaces.md).

For the full list of operations that are available in the Veeam Backup & Replication web UI, see [Veeam Backup & Replication Web UI](vbr_web_console.md).
