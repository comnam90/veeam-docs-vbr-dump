# Connecting to Existing Appliances


If you have already [deployed a backup appliance](azure_deploying_appliance.md), you can add the appliance to the backup infrastructure:

1. [Launch the New backup appliance wizard](azure_adding_appliance_wizard.md).
2. [Specify a deployment mode](azure_adding_appliance_mode.md).
3. [Specify service account settings](azure_adding_appliance_account.md).
4. [Specify an Azure subscription](azure_adding_appliance_subscription.md).
5. [Choose the appliance that you want to connect to](azure_adding_appliance_vm.md).
6. [Specify the connection type](azure_adding_appliance_connection.md).
7. [Specify a user whose credentials will be used to connect to the appliance](azure_adding_appliance_credentials.md).
8. [Configure repository settings](azure_adding_appliance_repository.md).
9. [Wait for the appliance to be added to the backup infrastructure](azure_adding_appliance_apply.md).
10. [Finish working with the wizard](azure_adding_appliance_finish.md).
