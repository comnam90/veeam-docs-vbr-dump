# Data Recovery (All Platforms)


Veeam Backup & Replication provides platform-specific data recovery methods as well as platform-independent methods:

* [VM Recovery](vm_recovery_all.md) — to restore entire VMs to different data protection environments: to VMware vSphere, Hyper-V, Amazon EC2 and so on.
* [Disk Recovery](disk_recovery_all.md) — to publish and export disks.
* [Guest OS File Restore](guest_file_recovery.md) — to recover individual guest OS files and folders directly from image-level backups, replicas and storage snapshots.
* [Application Item Restore](restore_veeam_explorers.md) — to restore individual application items with Veeam Explorers.
* [Active Directory Forest Restore](ad_forest_restore.md) — to recover an entire Microsoft Active Directory forest.
