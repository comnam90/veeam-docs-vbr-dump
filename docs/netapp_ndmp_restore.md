# Restoring NetApp NDMP Volumes from Tape


Before you perform NetApp NDMP volume restore from tape, check the [prerequisites and limitations](file_from_tape_before_you_begin.md#ndmp).

If the tapes are online in your tape device, Veeam Backup & Replication will get the needed data automatically. If the tapes are offline, Veeam Backup & Replication will list the names of the required tapes.

To restore NetApp NDMP volumes, use the Restore from Tape wizard:

1. [Launch the Restore from Tape wizard](restore_netapp_ndmp_launch.md).
2. [Choose volumes to restore](restore_netapp_ndmp_objects.md).
3. [Specify restore destination](restore_netapp_ndmp_destination.md).
4. [Specify restore options](restore_netapp_ndmp_options.md).
5. [Finish working with the wizard](restore_netapp_ndmp_summary.md).
