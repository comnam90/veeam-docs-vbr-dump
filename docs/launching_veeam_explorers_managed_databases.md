# Launching Veeam Explorer from RDS Backups


To launch Veeam Explorer for Microsoft SQL Server from an RDS backup created by Veeam Backup for AWS, perform the steps specified in [Restoring RDS Databases](aws_rds_database_restore.md#explorer).

For more information about using Veeam Explorer for Microsoft SQL Server, see [Restoring from RDS Backups](vesql_restore_rds.md).
