# Restoring to Another Server


To restore a single Microsoft SQL Server database to another server, use the Restore wizard.

1. [Launch the Restore wizard](vesql_restore_web_ui_single_tas_wizard.md).
2. [Specify a restore point](vesql_restore_web_ui_single_tas_restore_point.md).
3. [Fine-tune the restore point](vesql_restore_web_ui_single_tas_fine_tune.md).
4. [Specify the target server](vesql_restore_web_ui_single_tas_target_server.md).
5. [Specify Always On restore options](vesql_restore_web_ui_single_tas_always_on.md).
6. [Specify files location](vesql_restore_web_ui_single_tas_files_location.md).
7. [Specify the recovery state](vesql_restore_web_ui_single_tas_recovery_state.md).
8. [Review the restore summary](vesql_restore_web_ui_single_tas_summary.md).
