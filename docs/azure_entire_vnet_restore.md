# Performing Entire Virtual Network Configuration Restore


In case of unexpected configuration changes, you can restore the entire virtual network configuration from a virtual network configuration backup. Veeam Plug-in for Microsoft Azure allows you to restore the virtual network configuration to the original location or to a new location.

To restore the entire virtual network configuration, perform the following steps:

1. [Launch the Virtual Network Restore wizard](azure_entire_vnet_restore_wizard.md).
2. [Select a region and a restore point](azure_entire_vnet_restore_point.md).
3. [Select a service account](azure_entire_vnet_restore_account.md).
4. [Choose a restore mode](azure_entire_vnet_restore_mode.md).
5. [Configure additional restore settings](azure_entire_vnet_restore_zone_mapping.md).
6. [Specify a restore reason](azure_entire_vnet_restore_reason.md).
7. [Finish working with the wizard](azure_entire_vnet_restore_finish.md).
