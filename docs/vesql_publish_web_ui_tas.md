# Publishing to Specified Server


Publishing to the specified server allows you to select a target Microsoft SQL Server machine to which you can publish your databases.

To publish data, do the following:

1. [Launch the Publish Database wizard](vesql_publish_web_ui_tas_wizard.md).
2. [Specify a restore point](vesql_publish_web_ui_tas_restore_point.md).
3. [Fine-tune the restore point](vesql_publish_web_ui_tas_fine_tune.md).
4. [Specify the target server](vesql_publish_web_ui_tas_target_server.md).
5. [Review the publishing summary](vesql_publish_web_ui_tas_summary.md).
