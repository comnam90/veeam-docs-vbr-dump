# Adding NFS File Share Using Web UI


Before you add an NFS file share to the inventory of the virtual infrastructure, consider the following:

* The file share meets requirements listed in [Platform Support](https://helpcenter.veeam.com/docs/vbr/userguide/platform_support.html?ver=13#unstructured-data).
* If you plan to use a dedicated backup proxy server or cache repository, make sure these components are added in Backup Infrastructure.

To add an NFS file share as a source of unstructured data using web UI, do the following:

1. [Launch Add NFS File Share wizard](file_share_backup_nfs_share_launch_wizard_web.md).
2. [Specify NFS file share settings](file_share_backup_nfs_share_settings_web.md).
3. [Specify file share processing settings](file_share_backup_nfs_share_processing_settings_web.md).
4. [Finish working with wizard](file_share_backup_nfs_share_summary_web.md).
