# Step 2. Specify Retrieval Mode


At the Retrieval Mode step of the wizard, select the desired retrieval option. The set of available options differs depending on the archive storage provider. For information on the retrieval modes for different archive storage options, see [Data Retrieval](archive_tier_retrieval.md).
