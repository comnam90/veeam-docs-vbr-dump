# Creating New Repositories


To add a new repository, do the following:

1. [Launch the Add External Repository wizard](aws_add_s3_launch.md).
2. [Specify an appliance that will manage the backup repository, and provide a name and description for the repository](aws_add_s3_appliance.md).
3. [Specify AWS account settings](aws_add_s3_account.md).
4. [Specify an IAM role](aws_add_s3_role.md).
5. [Specify an Amazon S3 bucket](aws_add_s3_bucket.md).
6. [Enable data encryption](aws_add_s3_encryption.md).
7. [Specify mount server settings](aws_add_s3_mount_server.md).
8. [Specify an S3 interface endpoint](aws_add_s3_s3endpoint.md).
9. [Wait for the repository to be added to the backup infrastructure](aws_add_s3_apply.md).
10. [Finish working with the wizard](aws_add_s3_finish.md).
