# Creating Policy for Linux Computers Using Web UI


To back up data of a computer protected with Veeam Agent for Linux, you can configure a Veeam Agent backup policy in Veeam Backup & Replication.

Before configuring a Veeam Agent backup policy, [check prerequisites](agent_policy_before_linux_web.md). Then [launch the New Agent Backup Job wizard](agent_policy_launch_linux_web.md), [select the job mode](agent_policy_protection_linux_web.md), and follow the wizard steps to define settings for the backup policy:

1. [Specify job name and description](agent_policy_name_linux_web.md).
2. [Select computers to back up](agent_policy_comp_linux_web.md).
3. [Select backup mode](agent_policy_mode_linux_web.md).
4. [Specify backup scope](agent_policy_scope_linux_web.md).
5. [Specify backup storage settings](agent_policy_target_set_linux_web.md).
6. [Specify guest processing settings](agent_policy_guest_linux_web.md).
7. [Specify the backup schedule](agent_policy_schedule_linux_web.md).
8. [Review backup policy settings](agent_policy_review_linux_web.md).
