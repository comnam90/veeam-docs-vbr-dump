# Adding Sangfor aSV Server to Backup Infrastructure


To add a Sangfor aSV server to the backup infrastructure, do the following:

1. [Launch the New Sangfor aSV Server wizard](sangfor_server_add_launch.md).
2. [Specify the Sangfor aSV server domain name or IP address](sangfor_server_add_name.md).
3. [Enter credentials to access the Sangfor aSV server](sangfor_server_add_credentials.md).
4. [Apply Sangfor aSV server settings](sangfor_server_add_apply.md).
5. [Finish working with the wizard](sangfor_server_add_summary.md).
