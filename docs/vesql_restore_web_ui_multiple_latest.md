# Restoring Latest State


You can restore the latest available state of multiple Microsoft SQL Server databases. You can select databases from a specific server instance or across all instances on the machine.

To restore the latest available state of multiple databases, use the Restore wizard.

1. [Launch the Restore wizard](vesql_restore_web_ui_multiple_latest_wizard.md).
2. [Select databases you want to restore](vesql_restore_web_ui_multiple_latest_select_databases.md).
3. [Review the restore summary](vesql_restore_web_ui_multiple_latest_summary.md).
