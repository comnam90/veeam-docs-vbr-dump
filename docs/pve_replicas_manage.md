# Managing Replicated Data


Veeam Backup & Replication stores information about all replicated Proxmox VE VMs in the configuration database and keeps replicas synchronized with original VMs so that you can fail over to them if a disaster strikes your production site. You can manage created replicas in several ways: view replica properties, rescan replicas to update information about them, or remove replicas that you no longer need from the configuration or from the host.
