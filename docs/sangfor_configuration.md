# Configuring Veeam Plug-In for Sangfor aSV


To start working with Veeam Plug-in for Sangfor aSV, perform a number of steps for its configuration:

1. [Configure backup repositories](sangfor_configure_repository.md) where Veeam Backup & Replication will store backups of Sangfor aSV VMs.
2. [Connect to Sangfor aSV servers](sangfor_server_add.md) that administer Sangfor aSV resources you want to protect.
3. [Deploy workers](sangfor_workers.md) that will transfer backup traffic.
4. [[Optional] Configure email settings and notifications](sangfor_general_settings.md).
