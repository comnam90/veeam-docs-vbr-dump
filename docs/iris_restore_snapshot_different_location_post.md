# Step 7. Perform Post-Restore Operations


After the restore wizard completes a restore from storage snapshot, perform the following manual steps on the target ODB server:

1. Stop the InterSystems IRIS instance.
2. (Optional) Clean up the file system from unnecessary files.
3. (Optional) Convert the snapshot clones from thin to thick provisioning.
4. Start the InterSystems IRIS instance.
