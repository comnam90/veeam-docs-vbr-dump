# Step 7. Perform Post-Restore Operations


After the restore wizard completes a restore from storage snapshot, perform the following manual steps on the target ODB server:

1. (Optional) Clean up the file system from unnecessary files.
2. (Optional) Convert the snapshot clones from thin to thick provisioning to prevent data loss after removing the storage system from Veeam Backup & Replication.
3. Start the InterSystems IRIS instance.
