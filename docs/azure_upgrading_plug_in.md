# Upgrading Plug-In


To upgrade Veeam Plug-in for Microsoft Azure, do the following:

1. Install the new version of Veeam Plug-in for Microsoft Azure as described in section [Deploying Plug-In](azure_deploying_plug_in.md).
2. Upgrade backup appliances from the Veeam Backup & Replication console as described in section [Updating Appliances Using Console](azure_updating_console.md).
