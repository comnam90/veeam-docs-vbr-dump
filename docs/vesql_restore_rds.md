# Restoring from RDS Backups


This section explains how to restore Microsoft SQL Server databases from RDS backups created with Veeam Backup for Amazon Web Services. You can use Veeam Explorer for Microsoft SQL Server to restore such databases to an on-premise Microsoft SQL Server machine.
