# Creating Job for Linux Computers Using Console


To back up data of a computer protected with Veeam Agent for Linux, you can configure a Veeam Agent backup job in Veeam Backup & Replication.

Before configuring a Veeam Agent backup job, [check prerequisites](agent_job_before_linux.md). Then use the New Agent Backup Job wizard to define settings for the backup job.

1. [Launch the New Agent Backup Job wizard](agent_job_launch_linux.md).
2. [Select the job mode](agent_job_protection_linux.md).
3. [Specify job name and description](agent_job_name_linux.md).
4. [Select computers to back up](agent_job_comp_linux.md).
5. [Select backup mode](agent_job_mode_linux.md).
6. [Specify backup scope](agent_job_scope_linux.md).
7. [Specify backup storage settings](agent_job_target_set_linux.md).
8. [Specify advanced backup settings](agent_job_advanced_linux.md).
9. [Specify secondary backup target](agent_job_linux_secondary_target.md).
10. [Specify guest processing settings](agent_job_guest.md).
11. [Specify the backup schedule](agent_job_schedule_linux.md).
12. [Review backup job settings](backup_job_review_linux.md).
