# Step 1. Launch Restore Wizard


To launch the Restore wizard, do the following:

1. In the navigation pane, select the PostgreSQL server or an instance.
2. On the Server or Instance tab, select Restore Databases > Restore to another server.

Alternatively, you can right-click the server or an instance and select Restore Databases > Restore to another server.
