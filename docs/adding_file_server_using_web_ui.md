# Adding File Server Using Web Ui


To add a managed Windows or Linux server as a source of unstructured data using web UI, do the following:

1. [Launch New File Server Wizard](file_share_backup_managed_server_share_launch_wizard_web.md)
2. [Add the managed server as a file server.](file_share_backup_managed_server_file_server_web.md)
3. [Specify file server processing settings.](file_share_backup_managed_server_share_processing_settings_web.md)
4. [Review the components to be installed](file_share_backup_managed_server_share_review_web.md).
5. [Finish working with wizard](file_share_backup_managed_server_share_summary_web.md).
