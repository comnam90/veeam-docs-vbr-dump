# Step 2. Create Private Endpoints for Cosmos DB Account


To allow backup appliances access to the databases that you want to protect, you must create private endpoints for your Cosmos DB for PostgreSQL account.

You must create a separate private endpoint for every VNet to which worker instances are connected. To create a private endpoint, complete the following steps:

1. [Launch the Create a private endpoint wizard](azure_pne_cosmos_db_wizard.md).
2. [Configure private endpoint settings](azure_pne_cosmos_db_endpoint.md).
3. [Specify resource settings](azure_pne_cosmos_db_resource.md).
4. [Specify network settings](azure_pne_cosmos_db_configuration.md).
5. [Specify DNS settings](azure_pne_cosmos_db_dns.md).
6. [Assign tags](azure_pne_cosmos_db_tags.md).
7. [Finish working with the wizard](azure_pne_cosmos_db_finish.md).
