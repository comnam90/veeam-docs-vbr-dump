# Adding AWS Organizations


To add an AWS Organization to the backup appliance, do the following:

1. [Launch the Add Organization wizard](aws_organization_add_launch.md).
2. [Specify a name and description for the organization](aws_organization_add_name.md).
3. [Specify IAM roles that will be used to perform operations with the organization resources](aws_organization_add_settings.md).
4. [Specify an organization scope](aws_organization_add_scope.md).
5. [Finish working with the wizard](aws_organization_add_review.md).
