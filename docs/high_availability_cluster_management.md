# Managing High Availability Cluster


You can manage your HA cluster in various ways: edit settings of the primary node, edit settings of the cluster itself, such as the cluster IP address, external IP addresses, or cluster hostname, rescan the primary node, check its statistics, or disassemble your HA cluster.
