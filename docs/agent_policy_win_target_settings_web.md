# Step 8. Specify Backup Storage Settings


Specify backup storage settings for the Veeam Agent backup policy:

* [Local storage settings](agent_policy_win_target_drive_web.md) — if you have selected the Local storage option at the [Destination](agent_policy_win_destination_web.md) step of the wizard.

* [Shared folder settings](agent_policy_win_target_share_web.md) — if you have selected the Shared folder option at the [Destination](agent_policy_win_destination_web.md) step of the wizard.

* [Veeam backup repository settings](agent_policy_win_target_vbr_web.md) — if you have selected the Veeam backup repository option at the [Destination](agent_policy_win_destination_web.md) step of the wizard.
