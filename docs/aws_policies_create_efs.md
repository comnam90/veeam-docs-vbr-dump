# Creating EFS Backup Policies


To create a backup policy, do the following:

1. [Launch the Add EFS Policy wizard](aws_add_policy_launch_efs.md)
   .
2. [Specify a backup policy name and description](aws_add_policy_name_efs.md)
   .
3. [Specify a data protection scope](aws_add_policy_scope_efs.md)
   .
4. [Configure backup source settings](aws_add_policy_source_settings_efs.md)
   .
5. [Enable indexing for the processed file systems](aws_add_policy_indexing_efs.md)
   .
6. [Configure backup target settings](aws_add_policy_target_settings_efs.md)
   .
7. [Specify a schedule for the backup policy](aws_add_policy_schedule_retention_efs.md)
   .
8. [Enable AWS tags assignment](aws_add_policy_target_settings_tags_efs.md)
   .
9. [Configure automatic retry settings and notification settings for the backup policy](aws_add_policy_retry_notification_efs.md)
   .
10. [Review estimated cost of the selected EFS file systems](aws_add_policy_cost_efs.md)
    .
11. [Finish working with the wizard](aws_add_policy_finish_efs.md)
    .
