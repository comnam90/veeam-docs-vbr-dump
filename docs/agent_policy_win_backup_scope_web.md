# Step 6. Specify Backup Scope Settings


The Objects step of the wizard is available if you chose to create volume-level or file-level Veeam Agent backups. Specify backup scope for the Veeam Agent backup policy:

* [Specify volumes to back up](agent_policy_win_volumes_web.md) — if you have selected the Volume-level backup option at the [Backup Mode](agent_policy_win_mode_web.md) step of the wizard.
* [Specify folders to back up](agent_policy_win_folders_web.md) — if you have selected the File-level backup option at the [Backup Mode](agent_policy_win_mode_web.md) step of the wizard.
