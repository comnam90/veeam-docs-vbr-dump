# Step 5. Configure Backup Target Settings


By default, backup policies create only backups of processed DynamoDB tables. At the Targets step of the wizard, you can specify the following backup target settings:

* [Specify backup vaults where the backup appliance will store DynamoDB backups](aws_add_policy_target_settings_backups_dynamo.md).
* [Instruct the backup appliance to copy DynamoDB backups to other AWS Regions](aws_add_policy_target_settings_backup_copy_dynamo.md).
* [Instruct the backup appliance to store DynamoDB backups in a cold storage tier](aws_add_policy_target_settings_backup_archive_dynamo.md).
