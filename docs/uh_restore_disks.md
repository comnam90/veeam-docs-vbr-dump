# Performing Disk Restore


In case a disaster strikes, you can restore a disk of a VM running on a universal hypervisor from a backup. Veeam Plug-in for Universal Hypervisor API allows you to attach the restored disk to the original VM or any other VM running on a universal hypervisor. To restore a disk attached to a protected VM, do the following:

1. [Launch the Virtual Disk Restore wizard](uh_restore_disks_launch.md).
2. [Select a VM](uh_restore_disks_select_disks.md).
3. [Select a restore point](uh_restore_disks_restore_point.md).
4. [Configure mapping settings](uh_restore_disks_mapping.md).
5. [Specify a reason for the restore](uh_restore_disks_reason.md).
6. [Finish working with the wizard](uh_restore_disks_summary.md).
