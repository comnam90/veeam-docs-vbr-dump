# Restoring Containers to Another Location


To restore Active Directory containers to another location, do the following:

1. [Launch the Restore wizard](vead_restore_web_ui_containers_tas_wizard.md).
2. [Specify connection parameters](vead_restore_web_ui_containers_tas_connection_parameters.md).
3. [Specify the restore location](vead_restore_web_ui_containers_tas_location.md).
4. [Specify password restore options](vead_restore_web_ui_containers_tas_password.md).
5. [Specify the account state](vead_restore_web_ui_containers_tas_account_state.md).
6. [Specify restore options](vead_restore_web_ui_containers_tas_options.md).
7. [Specify attributes to restore](vead_restore_web_ui_containers_tas_attributes.md).
8. [Review the restore summary](vead_restore_web_ui_containers_tas_summary.md).
