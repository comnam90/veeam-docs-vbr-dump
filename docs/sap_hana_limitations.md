# Considerations and Limitations


Before you start using Veeam Plug-In for SAP HANA, consider the following:

* Veeam Plug-In transfers backup data to the Veeam backup repository only when you perform the backup using SAP Backint.

* Backups created by Veeam Plug-Ins cannot be used as a source for file to tape jobs. For information about backup to tape support, see [Backup to Tape](plugins_sap_hana_backup_to_tape.md).
