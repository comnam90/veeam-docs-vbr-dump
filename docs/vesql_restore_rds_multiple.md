# Restoring Multiple Databases


To restore multiple databases to an on-premise Microsoft SQL Server machine, use the Restore wizard.

1. [Launch the Restore wizard](vesql_restore_rds_multiple_tas_wizard.md).
2. [Select databases you want to restore](vesql_restore_rds_multiple_tas_select_databases.md).
3. [Specify a restore point](vesql_restore_plugin_multiple_tas_specify_restore_point.md).
4. [Specify the target server](vesql_restore_plugin_multiple_tas_specify_target_server.md).
5. [Specify files location](vesql_restore_plugin_multiple_tas_specify_files_location.md).
