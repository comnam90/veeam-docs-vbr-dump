# Configuring General Settings


Veeam Plug-in for Microsoft Azure allows you to configure general settings that are applied to all performed operations and deployed architecture components:

* [Enable the private network deployment functionality and choose a messaging service that will be used to transfer data](azure_deployment_mode.md).
* [Define for how long obsolete snapshots and session records will be retained](azure_configuring_global_retention.md).
* [Provide certificates to secure connections between Veeam Backup for Microsoft Azure architecture components](azure_working_with_certificates.md).
* [Configure notification settings for automated delivery of reports](azure_configuring_notification_settings.md).

* [Change the time zone set on the backup appliance](azure_changing_time_zone.md).
* [Configure single sign-on settings to retrieve user identities from an identity provider](azure_configuring_sso.md).
