# Creating DynamoDB Backup Policies


To create a backup policy, do the following:

1. [Launch the Add DynamoDB Policy wizard](aws_add_policy_launch_dynamo.md)
   .
2. [Specify a backup policy name and description](aws_add_policy_name_dynamo.md)
   .
3. [Specify a data protection scope](aws_add_policy_scope_dynamo.md)
   .
4. [Configure backup source settings](aws_add_policy_source_settings_dynamo.md)
   .
5. [Configure backup target settings](aws_add_policy_target_settings_dynamo.md)
   .
6. [Specify a schedule for the backup policy](aws_add_policy_schedule_retention_dynamo.md)
   .
7. [Enable AWS tags assignment](aws_add_policy_target_settings_tags_dynamo.md)
   .
8. [Configure automatic retry settings and notification settings for the backup policy](aws_add_policy_retry_notification_dynamo.md)
   .
9. [Review estimated cost of the selected DynamoDB tables](aws_add_policy_cost_dynamo.md)
   .
10. [Finish working with the wizard](aws_add_policy_finish_dynamo.md)
    .
