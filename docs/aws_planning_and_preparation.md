# Planning and Preparation


Before you start using Veeam Plug-in for AWS, consider the following requirements:

* [Hardware and software requirements](aws_system_requirements.md).
* [Network ports that must be open to ensure proper communication of solution architecture components](aws_ports.md).
* [AWS services to which backup appliances must have outbound internet access](aws_system_requirements_aws_services.md).
* [Permissions that must be assigned to accounts used to perform operations started using the Veeam Backup & Replication console](aws_req_permissions.md).
* [IAM permissions that must be assigned to IAM roles or IAM users used to perform operations started using the Web UI](aws_system_requirements_permissions.md).
* [Considerations and limitations that should be kept in mind before you deploy backup appliances](aws_limitations.md).
* [Sizing and Scalability Guidelines](aws_sizing_guide.md).
