# Creating Protection Group for Microsoft Active Directory Objects Using Web UI


Before you create a protection group for Microsoft Active Directory objects, [check prerequisites](ad_objects_before_web.md). Then use the Add Protection Group wizard to configure a protection group.

1. [Launch the New Protection Group wizard](ad_objects_launch_web.md).
2. [Specify protection group name and description](ad_objects_name_web.md).
3. [Specify Active Directory objects](protection_group_ad_web.md).
4. [Exclude objects from the protection group](protection_group_exclusions_web.md).
5. [Specify authentication settings](protection_group_accounts_web.md).
6. [Specify discovery and deployment options](ad_objects_options_web.md).
7. [Specify advanced protection group settings](ad_objects_advanced_web.md).
8. [Review components](ad_objects_review_web.md).
9. [Finish working with the wizard](ad_objects_finish_web.md).
