# Editing Backup Policy Settings


You can edit backup policies in the backup appliance Web UI only. However, you can launch the edit policy wizard directly from the Veeam Backup & Replication console. To do that, do the following:

1. In the Veeam Backup & Replication console, open the Home view.
2. Navigate to Jobs.
3. Select the necessary backup policy and click Edit on the ribbon.

Alternatively, you can right-click the policy and select Edit.

Veeam Backup & Replication will open the Edit Policy wizard in a web browser. Complete the wizard as described in section [Creating EC2 Backup Policies](aws_add_policy_name.md), [Creating RDS Backup Policies](aws_add_policy_name_rds.md), [Creating DynamoDB Backup Policies](aws_policies_create_dynamo.md), [Creating Redshift Backup Policies](aws_policies_create_redshift.md), [Creating EFS Backup Policies](aws_add_policy_name_efs.md), [Creating FSx Backup Policies](aws_policies_create_fsx.md) or [Editing VPC Configuration Backup Policy](aws_policies_edit_vpc.md).
