# Creating Object Storage Backup Jobs Using Web UI


Before you create an object storage backup job, check [prerequisites](os_before_you_begin_web.md).

To create an object storage backup job, use the New Backup Job wizard:

1. [Launch the New Backup Job wizard](os_backup_job_launch_web.md).
2. [Specify the job name and description](os_backup_job_name_web.md).
3. [Select objects to back up](os_backup_job_objects_web.md).
4. [Specify backup repository settings](os_backup_job_target_repository_web.md).
5. [Specify advanced backup settings](os_backup_job_advanced_settings_web.md).
6. [Specify archive repository settings](os_backup_job_archive_repository_web.md).
7. [Define the job schedule](os_backup_job_schedule_web.md).
8. [Finish working with the wizard](os_backup_job_finish_web.md).
