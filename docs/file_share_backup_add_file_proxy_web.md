# Adding General-Purpose Backup Proxies Using Web UI


You must add to the backup infrastructure one or more backup proxies that you plan to use for moving backup data in the unstructured data backup or Veeam Agent and storage system snapshot integration.

To add a backup proxy using Veeam Backup & Replication web UI:

1. [Launch the New Backup Proxy wizard](file_share_new_proxy_launch_web.md).

1. [Choose a server](file_share_new_proxy_server_web.md).
2. [Finish working with the wizard](file_share_new_proxy_summary_web.md)
