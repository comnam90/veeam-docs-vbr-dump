# Performing Failover and Failback


In various disaster recovery scenarios, Veeam Backup & Replication allows you to perform the following operations using replicated data:

* [Perform failover](pve_failover_run.md) — switch operations from original VMs in the production site to their replicas in the disaster recovery site.
* [Finalize failover](pve_failover_finalize.md) — fail back to original VMs or permanently switch to their replicas.
* [Undo failover](pve_failover_undo.md) — power off VM replicas and roll back to the original VM state before failover.
