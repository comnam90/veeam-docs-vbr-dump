# Creating Job for Windows Computers Using Web UI


To back up data of a computer protected with Veeam Agent for Microsoft Windows, you can configure a Veeam Agent backup job in Veeam Backup & Replication.

Before configuring a Veeam Agent backup job, [check prerequisites](agent_job_before_web.md). Then [launch the New Agent Backup Job wizard](agent_job_launch_web.md), [select the job mode](agent_job_protection_mode_web.md), and follow the wizard steps to define settings for the backup job:

1. [Specify job name and description](agent_job_name_web.md).
2. [Select computers to back up](agent_job_scope_web.md).
3. [Select backup mode](agent_job_mode_web.md).
4. [Specify backup scope](agent_job_backup_scope_web.md).
5. [Specify backup storage settings](agent_job_target_settings_web.md).
6. [Specify guest processing settings](agent_job_vss_web.md).
7. [Specify the backup schedule](agent_job_schedule_web.md).
8. [Review backup job settings](agent_job_review_web.md).
