# Universal Hypervisors


Veeam Backup & Replication offers various data protection and disaster recovery features for universal hypervisors that are designed to support the oVirt KVM-compatible REST API. Specifically, you can perform the following operations:

* Create backups of VMs running on a universal hypervisor and store them in backup repositories.

* Create VeeamZIP backups of VMs running on a universal hypervisor.

* Create several instances (copies) of the same backup data in different locations.
* Restore VMs from VM backups created by Veeam Plug-in for Universal Hypervisor API to supported universal hypervisors.

* Restore VMs from VMware ESXi and Microsoft Hyper-V to supported universal hypervisors.

* Restore VMs from Nutanix AHV, HPE Morpheus VM Essentials, oVirt KVM, Proxmox VE, Sangfor aSV, Scale Computing HyperCore, XCP-ng and Citrix XenServer backups to supported universal hypervisor.

* Restore VMs from Microsoft Azure, Amazon Web Services (AWS) and Google Cloud backups to supported universal hypervisors.
* Restore physical machines from backups created by Veeam Agents to supported universal hypervisors.

* Restore VMs from backups created by Veeam Plug-in for Universal Hypervisor API to Microsoft Azure, Amazon Web Services (AWS) and Google Cloud environments.
* Restore VMs from backups created by Veeam Plug-in for Universal Hypervisor API to Nutanix AHV, Proxmox VE, Scale Computing HyperCore, HPE Morpheus VM Essentials, Citrix XenServer, XCP-ng and oVirt KVM environments.

* Perform Instant Recovery of VMs and physical machines to VMware vSphere, Microsoft Hyper-V, Nutanix AHV and Proxmox VE environments.

* Restore application items (such as Microsoft Active Directory, Microsoft Exchange, Microsoft SharePoint, Microsoft DNS, PostgreSQL, Oracle Database and Microsoft SQL Server).
* Restore files and folders of VM guest OSes.
* Export disks of backed-up VMs running on a universal hypervisor to VMDK, VHD and VHDX formats.
* Mount disks of backed-up VMs running on a universal hypervisor to any server and access data in read-only mode.
