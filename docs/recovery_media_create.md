# Creating Veeam Recovery Media


You can use Veeam Backup & Replication to prepare Veeam Recovery Media for Veeam Agent for Microsoft Windows computers. Depending on how you plan to restore data, you can use the recovery media in one of the following scenarios:

* Local bare metal recovery — you burn the recovery media to a removable device, boot the computer that must be recovered from it and perform the restore locally on the computer side. To learn more about the local restore process, see [Restoring from Veeam Recovery Media Locally](integration_instant_restore_media_local.md).
* Remote bare metal recovery — you initiate and control the restore from the Veeam Backup & Replication web UI without physical access to the computer that must be recovered. To learn more, see [Restoring from Veeam Recovery Media Remotely](integration_instant_restore_media_remote.md).

You can create Veeam Recovery Media in one of the following ways:

* [Creating Veeam Recovery Media Using Console](recovery_media_create_console.md)
* [Creating Veeam Recovery Media Using Web UI](recovery_media_create_web.md)
