# Updating Backup Appliances


Backup appliances automatically notify you about newly released product versions and software package updates available for the operating system running on the backup appliance. However, starting from backup appliance version 5a, you can use the backup appliance Web UI to install software package updates only. To upgrade to a new version, follow the instructions provided in section [Upgrading Backup Appliances](azure_updating_console.md).
