# Performing SQL Restore Using Console


In case a disaster strikes, you can restore an Azure SQL database from an image-level backup. Veeam Backup & Replication allows you to restore one or more databases at a time, to the original location or to a new location. To learn how SQL restore works, see section [Performing SQL Restore Using Web UI](azure_performing_sql_restore_ui.md).

To restore Azure SQL databases, do the following:

1. [Launch the Restore to Microsoft Azure SQL Wizard](azure_restore_sql_wizard.md).
2. [Select a restore point](azure_restore_sql_database.md).
3. [Choose a restore mode](azure_restore_sql_mode.md).
4. [Specify target Azure SQL Server settings](azure_restore_sql_server.md).
5. [Specify a new name for the restored database](azure_restore_sql_name.md).
6. [Specify a restore reason](azure_restore_sql_reason.md).
7. [Finish working with the wizard](azure_restore_sql_summary.md).
