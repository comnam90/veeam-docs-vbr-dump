# Step 5. Configure Backup Target Settings


By default, backup policies create only backups of processed FSx file systems. At the Targets step of the wizard, you can specify the following backup target settings:

* [Specify backup vaults where the backup appliance will store FSx file system backups](aws_add_policy_target_settings_backups_fsx.md).
* [Instruct the backup appliance to copy FSx file system backups to other AWS Regions](aws_add_policy_target_settings_backup_copy_fsx.md).
