# Configuring Veeam Plug-In for Universal Hypervisor API


To start working with Veeam Plug-in for Universal Hypervisor API, perform a number of steps for its configuration:

1. [Configure backup repositories](uh_configure_repository.md) where Veeam Backup & Replication will store backups of VMs running on a universal hypervisor.
2. [Connect to servers](uh_server_add.md) that administer universal hypervisor resources you want to protect.
3. [Deploy workers](uh_workers.md) that will transfer backup traffic.
4. [[Optional] Configure email settings and notifications](uh_general_settings.md).
