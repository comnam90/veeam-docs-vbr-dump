# Restoring Configuration Data Using Web UI


To restore the appliance configuration database of a backup appliance using the appliance Web UI, do the following:

|  |
| --- |
| Important |
| Before you start the restore process, stop all policies that are currently running. |

1. [Launch the Configuration Restore wizard](aws_config_restore_launch.md).
2. [Choose a backup file](aws_config_restore_file.md).
3. [Review the backup file info](aws_config_restore_file_info.md).
4. [Choose restore options](aws_config_restore_options.md).
5. [Track the restore progress](aws_config_restore_progress.md).
6. [View the results of verification steps](aws_config_restore_verification.md).
7. [Finish working with the wizard](aws_config_restore_finish.md).
