# Upgrading to Veeam Plug-In for HPE Morpheus VM Essentials 2


To upgrade Veeam Plug-in for HPE Morpheus VM Essentials from version 1 to version 2, do the following:

1. Upgrade your Veeam Backup & Replication server to version 13.1 as described in the Veeam Backup & Replication User Guide, section [Upgrading to Veeam Backup & Replication 13](vbr_updating.md).
2. Complete the Components Update wizard as described in the Veeam Backup & Replication User Guide, section [Server Components Upgrade](components_update.md).
